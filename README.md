# Ward — контент-завод (пакет скиллов Claude)

Набор скиллов для Claude Code / Claude Desktop, который производит контент Ward от идеи до публикации: смысловые единицы контента → сценарии для AI-аватаров, посты Threads, карусели → визуал → публикация. Всё — на ДНК аудитории и голосе бренда Ward.

## Что внутри

| Папка | Что делает |
|---|---|
| `ward-content-factory/` | **Оркестратор.** Мастер настройки, статусы единиц контента в Teable, команды «сделай контент на неделю», «доведи пулю №N», «что в работе», проверка перед публикацией. Запускает остальные скиллы. |
| `parsing-ward/` | Ежедневный парсинг новостей крипторынка, отбор по рубрике под ЦА Ward → таблица → идеи для контента. |
| `eman-scenario/` | Сценарии коротких роликов, в том числе для озвучки AI-аватаром в HeyGen. |
| `threads-writer/` | Посты для Threads. |
| `carousel/` | Тексты и рендер каруселей Instagram (+ команда `/carousel`). |
| `zernio-posting/` | Публикация в Instagram / Threads через Zernio с записью в Teable. |
| `_ward/` | Общие материалы бренда: ДНК аудитории, голос бренда (ToV), дизайн-код. Скиллы читают их отсюда. |

## Установка

```bash
git clone <ссылка на этот репозиторий> ward-skills
cd ward-skills
bash install.sh
```

Скрипт делает симлинки всех скиллов и папки `_ward` в `~/.claude/skills/` и ставит команду `/carousel`. Потом в Claude: **«настрой завод»** — мастер проверит подключения и подскажет, что вписать.

## Что понадобится

- **Teable** — база с таблицами «Единицы контента», «Адаптации» и др. (схема — `ward-content-factory/knowledge/teable_schema.md`), API-токен.
- **Zernio** — API-ключ и подключённые аккаунты площадок.
- **HeyGen** — API-ключ, ID аватаров и голосов.
- **Higgsfield** — подключить как MCP в настройках Claude.
- Python 3; для рендера каруселей — Playwright + Chromium, `ffmpeg`, `exiftool` (подробно — `carousel/README.md`).

Ключи хранятся только в `config/secrets.yml` каждого скилла (образец — `secrets.example.yml`). Эти файлы в `.gitignore` и в репозиторий не попадают.

## Заглушки

Везде, где нужны ваши данные, стоят метки `{{...}}` (ID таблиц, аккаунтов, ник). Медиа (фото авторов, видеофоны, логотип) в репозиторий не входят — в соответствующих папках лежат `README.md` с описанием, что туда положить. Пока папки пустые, скиллы работают с предупреждением.
