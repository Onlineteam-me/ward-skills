# Ward — голос бренда и правила контента

Общий файл для всех скиллов пакета. Подробная аудитория — `ДНК клиента — новички.md` в этой же папке.

## Кто мы
**Ward** — украинский криптоброкер для скальперов: Discord-комьюнити, бесплатный курс (регистрация + KYC + депозит 50 USDT), платная программа «Практика» (500 USDT). Позиционирование — **«профессия без глянца»**: честный трейдинг как ремесло, без обещаний лёгких денег.

## Аудитория
Новички из СНГ без России: Украина и диаспора. Сегменты: Н-1 «Застрявший в найме», Н-2 «Вернувшийся», Н-3 «Эмигрант не по уровню», Н-4 «Крипто-хомяк», Н-5 «Обжёгшийся на глянце», плюс «буксующие» трейдеры. Без привязки к конкретной стране эмиграции.

## Голос
- Спокойный, честный, «свой трейдер за кофе». На равных, без снисхождения. «Тупых вопросов нет».
- Без глянца, капслока, «успешного успеха», Lambo, моря с ноутбуком (их можно только высмеивать).
- Минусы, стопы и рутину показываем так же охотно, как плюсы.

## Красные линии
- Никаких сумм-обещаний и «заработал за N дней». Нельзя «без риска», «гарантированно».
- Против теневого бана: в тексте на экране и подписях не писать «заработок / доход / быстрые деньги», внешних ссылок нет.
- Конкурентов, брокеров и биржи не называем («если обещают сигналы и гарантию — беги»).
- Военная тема — бережно, без эксплуатации травмы, акцент на навыках.
- Валюта только $ или USDT. Дисклеймер — «Не финансовая рекомендация».

## Призыв к действию (этап запуска)
Везде один: **«Подпишись, чтобы не потерять»** (допустимы естественные вариации). Курс, Discord, KYC, лид-магниты пока не продвигаем.
