# Логотип Ward (заглушка)

Файлы логотипа в пакет не входят — положите сюда официальные версии из брендбука:

| Файл | Что |
|---|---|
| `WARD_logo_white.png` (или `.svg`) | белый логотип на прозрачном фоне — для тёмных слайдов |
| `WARD_logo_black.png` | чёрный — для зелёного и светлого фона |
| `WARD_logo_green.png` | Emerald `#15C865` — для чёрного фона |
| `WARD_neon_reference.png` | референс неоновой вывески (для кадра подкастера и обложек) |

Минимум — PNG от 1200 px по ширине, лучше SVG. Правила использования — `../Дизайн-код Ward.md`, раздел «Логотип». Логотип накладывается при вёрстке из этих файлов и не генерируется нейросетью.
