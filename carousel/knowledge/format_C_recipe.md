# Формат C — Ньюсджекинг (новость от себя)

**Не отдельный визуальный стиль, а рецепт-композиция:** скелет формата A (фото лица бренда для узнаваемости) + слайд-пруф B2 (скрин источника). Визуал берётся из `visual_dna_format_A.md`, слайд-источник — из `build_cover.md` (ветка B2).

## Когда использовать

Злободневная новость / тренд / релиз / свежий кейс, который ты подаёшь **от себя** — чтобы аудитория:
1. ассоциировала новость с брендом (фото лица бренда, узнаваемость),
2. видела, что ты её **проработал** (слайд-источник = «это не выдумка, я проверил»).

Триггеры в запросе: «разбери новость», «ньюсджекинг», «вышла новость / релиз», «свежий тренд», ссылка на статью/пост/релиз + желание подать лично.

## Визуальная ДНК

= **формат A** (крем-беж `#EFEAE0`, без сетки, Inter, фото из `materials/фото_автора/`). Для слайда-источника допускается элемент из палитры B: тёмная карточка `#0A0A0A` + оранжевый штамп «ИСТОЧНИК» `#E85A2C`.

## Структура-рецепт

1. **Обложка (01) — ВСЕГДА фото лица бренда** (если папка фото пуста — типографская обложка, движок предупредит) + новостной хук (что произошло + цифра/почему важно). Никогда не скрин и не видео. 🔴 Хук по правилу «СУБЪЕКТ + ПОВОРОТ» (SKILL.md #27) — не голая цифра. 🔴 Kicker БЕЗ даты: «НОВОСТЬ · 16.07» запрещено (2026-07-19) — тематический ярлык («РЕЛИЗ», «ЭКСПЕРИМЕНТ», «РАЗБОР») либо пустой; дата остаётся только на скрине-источнике (слайд 02).
2. **Слайд-источник (02 или 03) — вид B2:** реальный скрин статьи/поста/репозитория в браузер-мокапе/карточке + штамп «ИСТОЧНИК» + kicker «это не выдумка — вот источник». Сборка: `workflows/build_cover.md` → ветка B2.
3. **Фото-каденция как в формате A** — по таблице визуальных слотов из `visual_dna_format_A.md` (на стандартной карусели 10 слайдов: фото на 01/03/09 + 1 видео на 06). **Видео-слот тоже работает** (`workflows/video_backgrounds.md`).
4. **Типографика-разбор:** что это значит → цифры/детали → что это меняет для новичка (без сумм-обещаний, см. правило 29).
5. **Финальный слайд (10)** — «Подпишись, чтобы не потерять», `{"layout":"cta"}` (правило 4).

> Важно: слайд-источник B2 **добавляется сверх** фото/видео-слотов, он не занимает слот из таблицы A. Обычно это слайд 02 или 03.

## Эталон

Раскладка эталона: фото на 01/06/10, скрин-источник на 02, остальное типографика. Собирается тем же движком `scripts/render.py` (макет `source` для слайда-пруфа). Готовых примеров-картинок в пакете нет.
