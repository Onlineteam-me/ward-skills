# ИСВП — Формулы хуков

**ИСВП = Интрига + Срочность + Выгода + Причастность**

Полный справочник: `materials/исвп-формула.md` + `title-frameworks.md`.

---

## Топ-5 комбинаций

### И+С — Интрига + Срочность *(сильнее всего для охвата)*
```
[Провокационное утверждение]
Пока ты не знаешь [X] — ты теряешь [Y]
```

### В+П — Выгода + Причастность *(для конкретного результата)*
```
Как [конкретная ЦА] получает [результат]
[Метод / формула] без [боль / барьер]
```

### И+В — Интрига + Выгода *(для образовательного контента)*
```
[Контринтуитивный факт или вопрос]
И вот что это меняет на практике
```

### С+П — Срочность + Причастность *(трендовые темы)*
```
Если ты [признак ЦА] — это происходит прямо сейчас
[Факт / угроза / возможность]
```

### И+С+В — тройной удар *(максимум вовлечения)*
```
[Неожиданная правда]
[Почему это срочно]
[Что ты получаешь понимая это]
```

## Элементы по отдельности

### И (Интрига)
- **Contradiction:** "Все говорят X — реальность Y"
- **Knowledge gap:** "Есть один нюанс в [теме] который меняет всё"
- **Provocative question:** "Что если [распространённое убеждение] — ложь?"

### С (Срочность)
- "Пока ты читаешь это — [мир/конкуренты] уже [делают X]"
- "Каждый день без [X] ты теряешь [Y]"

### В (Выгода)
- "Как [глагол] за [время / ресурс]"
- "[Действие] = [конкретный результат]"
- "Из [состояние A] в [состояние B]"

### П (Причастность)
- "Если ты [признак ЦА] — это для тебя"
- "Для тех кто [верит / строит / работает в X]"

## 🔴 Правило «СУБЪЕКТ + ПОВОРОТ» (2026-07-19, SKILL.md #27)

Хук обложки обязан называть, О ЧЁМ карусель. Голая цифра без субъекта — брак: интрига без опоры не цепляет, она непонятна.

**Формула:** `[кто/что случилось] + [конкретика-цифра] + [почему это ломает картину мира]`

| ❌ Голая цифра | ✅ Субъект + поворот |
|---|---|
| «$0.94 против $9. То же качество.» | «Китайский AI обошёл Claude. И стоит в 10 раз дешевле.» |
| «3× быстрее. И один в один с остальными.» | «AI ускоряет карьеру в 3 раза. И стирает тебя из профессии.» |
| «$73. 39 минут. Целый музыкальный клип.» | «AI снял музыкальный клип за $73. Продакшн брал за это тысячи.» |

**Два теста перед сдачей:**
1. **Тест холодного читателя:** закрой все слайды кроме 01. Понятно, О ЧЁМ карусель и ПОЧЕМУ листать? Если «о чём» отвечает только слайд 03 — хук бракованный.
2. **Чек «01 vs 03»:** сравни обложку с самым сильным контентным слайдом. Внутренний слайд интереснее обложки → перепиши хук, забрав его силу на обложку.

Происхождение: батч 2026-07-19 — все 3 карусели имели слайд 03 интереснее обложки, потому что хук состоял из цифр без субъекта, а конкретика с субъектом уезжала на 03.
