> **Статус: утверждено и зашито в `scripts/render.py`.** Это источник правды по макетам.
> Касается ТОЛЬКО скилла carousel-ward.

## 0. Три уровня (как комбинируются)

1. **Формат карусели** (скин): **A** фото-личность · **B** Higgsfield-объект/скрин + HTML · **C** ньюсджекинг (A-скелет + слайд-пруф).
2. **Макет слайда** (10 штук ниже): что в центре конкретного слайда.
3. **Компоненты-хром** (логотип, кикер-пилюля, счётчик, стрелка, буллеты, карточка): переиспользуемые элементы, включаются по формату.

Один бренд → 3 формата → 10 макетов → общий хром. Это всё ОДНА система.

## 1. Бренд-токены (зашиты в движок, JSON их не задаёт)

Источник — `_ward/Дизайн-код Ward.md`.

| Токен | Значение |
|---|---|
| Фон | `#000000` |
| Текст | `#FFFFFF` (на зелёном и белом — `#000000`) |
| **Акцент** | **Emerald `#15C865`** |
| Служебное (счётчик, ник) | Slate Grey `#738290`, приглушённая колонка `compare` — он же |
| Карточка | Slate при 16%, радиус 32 px, без тени |
| Заглушка фона | `#15C865 → #0B3D22 → #000000` из угла + зерно |
| Шрифт | **Только Montserrat**: заголовки 700, текст 400–500 |
| Заголовок | трекинг −60 от 80 px, −45 мельче; `line-height` 1.08; зазор до body ≥ 32 px |

### Темы слайда (`"theme"`)
- `black` — по умолчанию.
- `green` — заливка Emerald, чёрный текст. Для обложки или вывода, 1–2 раза на карусель. Финал `cta` зелёный сам.
- `white` — белый фон, чёрный текст + Emerald. Для контраста в середине.

### Компоненты-хром
- **Логотип + счётчик** — лев. верх, логотип из `_ward/логотип/`, цвет по теме.
- **Ник** — лев. низ, из `config/settings.yml → brand.nickname`; не задан — не печатается.
- **Кикер** — пилюля Emerald с чёрным текстом («РАЗБОР», «МИФ», «НОВИЧКУ»).
- **Стрелка →** — Emerald, прав. низ, «листай». *Опц.*
- **Буллеты** — точка Emerald + текст 34 px.
- Запретные зоны: прав. верх (счётчик IG), прав. низ (звук) — текст туда не ставить.

## 2. 🔴 ГЛАВНОЕ ПРАВИЛО ВИЗУАЛА: картинка — edge-to-edge, НИКОГДА не плашка

Любой визуал (Higgsfield, фото, видео) **заполняет кадр целиком** (правило 9 SKILL.md). Низ кадра уходит в чёрный, текст — поверх.

- **Картинка Higgsfield** генерируется по шаблонам дизайн-кода (раздел 8) в композиции «объект сверху, низ чёрный» → путь в `"bg"`/`"object"`.
- **Фото** — full-bleed + затемнение снизу, текст поверх.
- ❌ Запрещено: картинка в рамке, тайле или прямоугольнике по центру.

## 3. Схема `slides.json`

```json
{
  "title": "5_mifov_novichka",
  "format": "A",                 // A | B | C
  "chrome": { "arrow": false },  // стрелка «листай» на всю карусель
  "slides": [
    { "n":1, "layout":"cover-photo", "photo":"auto",
      "kicker":"МИФЫ", "hero":["5 мифов,","из-за которых",{"t":"новичок сливает депозит","accent":true}] },
    { "n":3, "layout":"object-list", "object":"auto",
      "kicker":"ЧЕК-ЛИСТ", "hero":["Перед первой","сделкой"],
      "items":["Стоп — до входа","Объём — минимальный","Журнал — каждая сделка","План — на сессию"] },
    { "n":6, "layout":"stat", "big":"~2", "unit":"года", "body":"средний путь от нуля до уверенной торговли" },
    { "n":10, "layout":"cta" }
  ]
}
```
`"auto"` для photo = рандом среди вертикальных из `materials/фото_автора/`; папка пуста → заглушка-градиент с предупреждением. Картинка Higgsfield — путь в `"bg"` или `"object"`; пока её нет — `"bg":"placeholder"` (движок напомнит заменить). `"glow"`: `tr`/`tl`/`br`/`bl` — угол свечения заглушки. `"theme"`: `black`/`green`/`white`. Ник — из `config/settings.yml`, можно переопределить полем `"nick"`. `accent:true` = Emerald.
