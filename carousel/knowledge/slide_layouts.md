# Дизайн-система carousel — спек для движка (v1, 2026-06-02)

> **Статус: утверждено и зашито в `scripts/render.py`.** Это источник правды по макетам.
> Касается ТОЛЬКО скилла carousel.
>
> ⚠️ Не отменяет семантическую «Слайд-палитру» из `structure_principles.md` (Cover/Context/Insight/Case/CTA — это про СМЫСЛ). Здесь — про ВИЗУАЛ (как сверстано).

---

## 0. Три уровня (как комбинируются)

1. **Формат карусели** (скин): **A** фото-личность · **B** Higgsfield-объект/скрин + HTML · **C** ньюсджекинг (A-скелет + слайд-пруф).
2. **Макет слайда** (10 штук ниже): что в центре конкретного слайда.
3. **Компоненты-хром** (закладка, кикер, счётчик, стрелка, буллеты, тёмная карточка): переиспользуемые элементы, включаются по формату.

Один бренд → 3 формата → 10 макетов → общий хром. Это всё ОДНА система.

## 1. Бренд-токены (зашиты в движок, JSON их не задаёт)

| Токен | Значение |
|---|---|
| Фон (cream) | `#EFEAE0` |
| Текст (black) | `#1A1A1A` |
| **Акцент (orange) — ЕДИНЫЙ** | **`#E85A2C`** (тёплый). 🔴 Старый «красный» `#E63A1F` НЕ использовать — поправить в шаблонах. |
| Тёмная карточка | `#0A0A0A`, radius 24px, тень `0 20px 60px rgba(232,90,44,.18)` |
| Сетка-grid | `#CFC4A8`, шаг 40px, opacity ~.32 — 🔴 **по умолчанию ВЫКЛ (чистый крем — дефолт).** Включать опционально, и НИКОГДА под full-bleed объектом/фото (мисматч «картинка сверху, клетки снизу»). |
| Шрифт | **Только Inter** (900 заголовки / 700-800 акценты / 600 body). Счётчик и кикер — тоже Inter (НЕ monospace: JetBrains Mono не вшит, моно-фоллбэк даёт «чужой» шрифт). Один шрифт на всё. |
| line-height заголовка | **≥ 1.05**; зазор заголовок→body **≥ 32px** (см. `typography_safety.md`) |

### Компоненты-хром
- **Счётчик** `NN / 10` — лев. верх, JetBrains Mono, 24-26px.
- **Ник** `{{НИК_АККАУНТА}}` (из `config/settings.yml → brand.nickname`) — лев. низ.
- **Моно-кикер** — вразрядку, uppercase, оранжевый («НАПРАВЛЕНИЕ 2 / 7», «ГАЙД · ONE USEFUL THING»).
- **Закладка** (bookmark) — оранжевый флажок лев. верх. *Опц.* (формат B).
- **Стрелка →** — оранжевая, прав. низ, «листай». *Опц.* (формат B).
- **Буллеты** — оранжевый кружок + чёрный bold текст 26-30px.
- Запретные зоны: прав. верх (счётчик IG), прав. низ (звук) — текст туда не ставить (стрелка → допустима, как в эталонах).

## 2. 🔴 ГЛАВНОЕ ПРАВИЛО ВИЗУАЛА: объект/фото — edge-to-edge, НИКОГДА не плашка

Любой визуал (Higgsfield-объект, фото, видео) **заполняет кадр или сливается с фоном — НИКОГДА не в рамке/тайле/прямоугольнике по центру** (правило 25 SKILL.md).

- **Higgsfield-объект** генерируется **на креме `#EFEAE0`** (см. `prompts/higgsfield_3d_object.md`) → ставится **во всю ширину, без рамки**, с мягкой тенью → сливается с фоном. Текст — ниже объекта.
- **Фото** — full-bleed на весь кадр + градиент снизу, текст поверх.
- ❌ Запрещено: объект на чужом (сером/белом) фоне, вставленный прямоугольником — выглядит «воткнуто».

✅ **Эталон «объект на креме» (как ДОЛЖНО):** объект сверху во всю ширину, низ плавно уходит в крем `#EFEAE0`, под ним кикер + заголовок + буллеты (макет `object-list`).

## 3. Схема `slides.json`

```json
{
  "title": "5_mifov_novichka",
  "format": "A",                 // A | B | C
  "chrome": { "bookmark": false, "arrow": false, "grid": false },  // по формату; A обычно всё false, B обычно true
  "slides": [
    { "n":1, "layout":"cover-photo", "photo":"auto",
      "kicker":"МИФЫ", "hero":["5 мифов,","из-за которых",{"t":"новичок сливает депозит","accent":true}] },
    { "n":3, "layout":"object-list", "object":"auto",
      "kicker":"ЧЕК-ЛИСТ", "hero":["Перед первой","сделкой"],
      "items":["Стоп — до входа","Объём — минимальный","Журнал — каждая сделка","План — на сессию"] },
    { "n":6, "layout":"stat", "big":"~2", "unit":"года", "body":"средний путь от нуля до уверенной торговли" },
    { "n":10, "layout":"cta" }
  ]
}
```
`"auto"` для photo/object = движок берёт по правилам (фото — рандом среди вертикальных из `materials/фото_автора/`; папка пуста → типографский фолбэк с предупреждением; объект — генерится отдельно на креме). Ник — из `config/settings.yml`, можно переопределить полем `"nick"`. `accent:true` = оранжевый.

## 4. Каталог макетов (10 + CTA)

| id | Что | Ключевые поля | Формат |
|---|---|---|---|
| `cover-photo` | обложка: фото full-bleed + хук снизу | photo, hero[], kicker | A / C |
| `cover-visual` | обложка: Higgsfield-объект **на креме edge-to-edge** + хук | object, hero[], kicker | B |
| `object-list` | объект на креме сверху + кикер + заголовок + буллеты (эталон энергетика/здоровье) | object, hero[], items[], kicker | B |
| `poster` | крупный тезис, акцент-слово, кремовый фон | hero[], caption | A / B |
| `photo-overlay` | фото full-bleed + заголовок + body снизу | photo, title[], body | A |
| `stat` | гигантская цифра + подпись | big, unit, body | A / B |
| `list` | заголовок + пункты на **тёмной карточке** | hero[], items[] | B |
| `insight` | `#NN` + тезис + пояснение | insight_no, hero[], caption | A / B |
| `quote` | крупная цитата (на креме или тёмной карточке) | quote, source | A / B |
| `compare` | две колонки vs (усиливает / режет) | hero[], left{title,items}, right{title,items} | B |
| `formula` | было→стало / A→B→C, красная линия | top_block, bottom_block, caption | A / B |
| `source` | скрин-пруф в мокапе + штамп ИСТОЧНИК | screenshot, caption, kicker | B / C |
| **`cta`** | **финал «Подпишись, чтобы не потерять» — верстает движок** (ник по центру крупно); текст — `materials/финальный_слайд.md` | опц. hero[], caption | все |

(Это 12 рабочих макетов + cta. «10» было ориентиром — добавили `object-list` и `compare` по эталонам/запросу.)

## 6. Что зашить в движок при сборке `render.py`

1. Единый оранжевый `#E85A2C` (поправить и шаблоны, где сейчас `#E63A1F`).
2. Правило edge-to-edge для объектов/фото (п.2) + генерация объекта на креме.
3. Типографика: line-height ≥1.05, зазор ≥32px, мин. размеры, bottom-стек.
4. Хром по флагам `chrome`.
5. 12 макетов из п.4 как функции; cta — финальный слайд «Подпишись, чтобы не потерять».
6. Пустые медиа-папки: фото → типографский фолбэк, видео → статичный слайд; везде предупреждение, не падение.

> Палитры-варианты (тёмный фон и т.п.) — отдельным слоем ПОЗЖЕ, после того как этот спек закроется движком и протестируется.
