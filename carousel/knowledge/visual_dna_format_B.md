# Visual DNA — Формат B (Гибрид Higgsfield + HTML)

**Когда использовать:** темы со скринами / схемами / списками брендов / "топ-N" / архетипы / репозитории / сравнения. Когда лицо бренда НЕ нужно на каждом слайде.

🔴 **Источник правды по визуалу — `_ward/Дизайн-код Ward.md`.** Здесь только то, как он ложится на формат B.

## Визуал

- Фон: чёрный `#000000`; без сетки и закладок
- Карточки: Slate Grey `#738290` при 16% непрозрачности, радиус 32 px, без цветных теней
- Акцент: Emerald `#15C865`; громкий слайд — заливка Emerald с чёрным текстом (1–2 раза на карусель)
- Заглушка вместо картинки Higgsfield: градиент `#15C865 → #0B3D22 → #000000` из угла + зерно (`"bg":"placeholder"`)

## Типографика

- Только **Montserrat**: заголовки Bold/SemiBold с плотным трекингом, текст Medium/Regular
- Счётчик и ярлыки — тоже Montserrat

## Структура

- 1 (cover) + N контентных + 1 CTA
- Контентные слайды = HTML/CSS/Playwright (можно с анимациями → MP4)

## Два вида обложки (B1 / B2)

У формата B обложка (слайд 1) бывает двух видов — выбор по источнику контента:

- **B1 — Higgsfield-визуал.** Тема/идея → сгенерированный предмет-метафора или сцена через `nano_banana_2` (без текста), типографика поверх. Для абстрактных/концептуальных тем. Промпт: `prompts/higgsfield_3d_object.md`. Сборка: `workflows/build_cover.md` (ветка B1).
- **B2 — Скриншот-источник.** Реальный скрин GitHub-репозитория / статьи / поста / сайта → кладётся в карточку или фоном, типографика + штамп «ИСТОЧНИК» поверх. Для тем-пруфов («вот реальный источник», топы инструментов, репозитории). Без Higgsfield. Сборка: `workflows/build_cover.md` (ветка B2). Техника наложения текста — как у видео-оверлея (`workflows/video_backgrounds.md`).
  - Может стоять и как обложка, и как слайд-пруф внутри карусели.

## Эталон формата B

Статичные слайды — единый движок `scripts/render.py` + `slides.json` (пример `templates/slides.example.json`). Анимации (HTML → MP4) — спецификация `knowledge/animation_specs.md`. Готовых примеров-архивов в пакете нет (медиа не передаются).
