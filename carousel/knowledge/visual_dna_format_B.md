# Visual DNA — Формат B (Гибрид Higgsfield + HTML)

**Когда использовать:** темы со скринами / схемами / списками брендов / "топ-N" / архетипы / репозитории / сравнения. Когда лицо бренда НЕ нужно на каждом слайде.

## Палитра

- Фон: `#EFEAE0` (cream)
- Сетка/grid: `#CFC4A8`, шаг 40px (анимированный медленный drift)
- Bookmark/закладка: оранжевая `#E85A2C` (top-left)
- Карточки: чёрные `#0A0A0A`, border-radius 24px, оранжевая тень
- Акцент: `#E85A2C` (тёплее, чем формат A)

## Типографика

- Заголовки: **Inter** weight 900
- Body: **Inter** weight 600-700
- Счётчики/моноширинные элементы: **JetBrains Mono**

## Структура

- 1 (cover) + N контентных + 1 dark-side / CTA
- Контентные слайды = HTML/CSS/Playwright (можно с анимациями → MP4)

## Два вида обложки (B1 / B2)

У формата B обложка (слайд 1) бывает двух видов — выбор по источнику контента:

- **B1 — Higgsfield-визуал.** Тема/идея → сгенерированный объект/статуя/3D через `nano_banana_2` (без текста), типографика поверх. Для абстрактных/концептуальных тем. Промпт: `prompts/higgsfield_3d_object.md`. Сборка: `workflows/build_cover.md` (ветка B1).
- **B2 — Скриншот-источник.** Реальный скрин GitHub-репозитория / статьи / поста / сайта → кладётся в карточку или фоном, типографика + штамп «ИСТОЧНИК» поверх. Для тем-пруфов («вот реальный источник», топы инструментов, репозитории). Без Higgsfield. Сборка: `workflows/build_cover.md` (ветка B2). Техника наложения текста — как у видео-оверлея (`workflows/video_backgrounds.md`).
  - Может стоять и как обложка, и как слайд-пруф внутри карусели.

## Эталон формата B

Статичные слайды — единый движок `scripts/render.py` + `slides.json` (пример `templates/slides.example.json`), стартовый HTML — `templates/slide_format_B_static.html`. Анимации (HTML → MP4) — спецификация `knowledge/animation_specs.md`. Готовых примеров-архивов в пакете нет (медиа не передаются).

## Запретные зоны

- Правый верх — счётчик IG ❌
- Правый низ — звук IG ❌

## Обязательные элементы

- Левый верх: bookmark + `NN/TT` (JetBrains Mono для стабильной ширины)
- Левый низ: ник аккаунта `{{НИК_АККАУНТА}}`
