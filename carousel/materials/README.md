# Материалы для каруселей

Этот каталог содержит справочные материалы и медиа. Читай по необходимости (не всё сразу — экономь токены).

## MD-файлы (быстрые выжимки для агента)

| Файл | Когда читать |
|---|---|
| `ца.md` | Перед каждой каруселью — попасть в боли/страхи/мифы/язык новичков Ward (сегменты Н-1…Н-5) и не нарушить анти-эстетику. |
| `позиционирование.md` | Перед каждой каруселью — «профессия без глянца», принципы профессии, tone of voice, красные линии, манифест-фразы. |
| `финальный_слайд.md` | Слайд 10 и призыв в подписи — «Подпишись, чтобы не потерять». |
| `исвп-формула.md` | На шаге «Сформулировать 5 вариантов хука» — оттуда берутся комбинации. |
| `title-frameworks.md` | Если карусель «полезная» (как-сделать / рейтинг / сравнение) — оттуда формула для заголовка. |

Полные исходники по бренду (если пакет ставился целиком) — `ward-skills/_ward/`: `Голос бренда Ward (ToV).md`, `ДНК клиента — новички.md`.

## Медиа-папки (сейчас заглушки)

| Папка | Что там | Если пусто |
|---|---|---|
| `фото_автора/` | Фото лица бренда для обложек и фото-слайдов (формат A/C) | Обложка и фото-слайды верстаются типографикой + предупреждение |
| `video_bg/` | Клипы для «живых» слайдов (1 на карусель) | Видео-слайд верстается статикой + предупреждение |

Что и в каком формате класть — `README.md` внутри каждой папки.

## Шрифты

`шрифты/` — открытые шрифты (лицензия OFL): **Inter** (основной, вшит в `render.py`), Onest, Unbounded, Manrope (кириллица) и Barlow Condensed (только латиница — для английских каруселей).
