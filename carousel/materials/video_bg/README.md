## Что сюда положить

- **Количество:** от 10 клипов (лучше 20–40 — чтобы между каруселями не было повторов; движок помнит последние 25 использованных).
- **Готовые клипы** (в корень этой папки): `*.mp4`, **1080×1350 (4:5), ≤15 сек, H.264 + faststart, БЕЗ аудиодорожки**.
- **Именование:** латиница, цифры, `_`, без пробелов — например `city_night_01.mp4`, `terminal_hands_02.mp4`.
- **Что снимать для Ward:** экран терминала/стакана, руки на клавиатуре, рабочее место трейдера, спокойный город/природа, ноутбук в дороге. Без глянца: никаких Lambo, яхт, пачек денег.
- **Сырьё** любого формата и соотношения — в `raw/`, потом обработать скриптом (он сам обрежет под 1080×1350, укоротит до 15 сек и уберёт звук):
  ```bash
  "<python с playwright>" scripts/process_video_bg.py
  ```

## Файлы-индексы (уже есть, пустые)

| Файл | Что это |
|---|---|
| `video_bg_index.json` | Теги клипов (`file`, `mood`, `scene`, `recommended_for`, `tags`). Сейчас `"clips": []`. После обработки — описать новые клипы здесь. Если индекс пуст, движок просто берёт любые `*.mp4` из папки |
| `_video_usage.json` | Журнал последних использованных клипов (ведёт `render.py` сам) |
| `_processed.json` | Журнал обработанного сырья (ведёт `process_video_bg.py` сам) |
| `raw/` | Сырьё для обработки |
| `.thumbs/` | Превью среднего кадра (создаёт `process_video_bg.py`) |

## Как пополнять

1. Закинуть исходники в `raw/`.
2. Запустить `scripts/process_video_bg.py` — обработает и сделает превью в `.thumbs/`.
3. Протегировать новые клипы в `video_bg_index.json` (mood / scene / recommended_for / tags).

Как использовать на слайдах — `workflows/video_backgrounds.md`.
