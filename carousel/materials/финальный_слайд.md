# Финальный слайд (10/10) и призыв в подписи — Ward

**Слайд 10 каждой карусели** = финальный призыв бренда. Он **не берётся из библиотеки картинок** — его верстает движок `scripts/render.py` по макету `cta`, в дизайн-коде Ward (заливка Emerald, чёрный Montserrat).

## Правило (см. SKILL.md правила 1 и 4)

- Карусель — **максимум 10 слайдов** (лимит API соцсетей на автопостинг).
- Из них: **9 контентных + 1 финальный** (если контента меньше — финальный всё равно последний).
- Counter на финальном слайде — `NN/NN` (на стандартной карусели `10/10`).

## Канонический текст (единый источник)

> **Подпишись, чтобы не потерять**

Это этап запуска Ward: курс, Discord, KYC и подарки за комментарий **не продвигаем**. Призыв везде один (допустимы естественные вариации — «Подпишись, чтобы не потерять разбор», «Сохрани и подпишись, чтобы не потерять» — но смысл не меняем и ничего не обещаем).

## Как выглядит слайд (зашито в render.py)

| Элемент | Значение |
|---|---|
| Hero | «Подпишись, / чтобы / не потерять» чёрным, крупно, по левому краю |
| Caption | опционально (поле `caption`), например «Здесь — честно про трейдинг как профессию» |
| Ник | `brand.nickname` из `config/settings.yml` — крупно под призывом (правило 6) |
| Логотип + counter | лев. верх, логотип чёрный из файла, `10/10` |
| Фон | Emerald `#15C865` |

В `slides.json`:
```json
{ "n": 10, "layout": "cta" }
```
Переопределить текст можно полями `hero` / `caption`, но по умолчанию — канон выше. 🔴 На слайде запрещены слова «заработок / доход / быстрые деньги» и внешние ссылки (теневой бан).

## Призыв в подписи под пост

Подпись **заканчивается** строкой призыва и дисклеймером:

```
…последний абзац контента.

Подпишись, чтобы не потерять.

Не финансовая рекомендация.
```

Шаблон всей подписи — `templates/caption_template.md`.
