# Фото автора / лица бренда — ЗАГЛУШКА

> 🟡 **Сейчас это заглушка: фото нет.** Скилл работает и без них — `render.py` выдаст предупреждение «папка фото автора пуста» и сверстает обложку и фото-слайды типографикой на креме (без фото). Формат A и C («бренд личности», ньюсджекинг) полноценно заработают, когда здесь появятся фото.

## Что сюда положить

- **Что:** фото человека, который «лицо» аккаунта (трейдер/ментор Ward), или атмосферные кадры рабочего места трейдера. Без глянца.
- **Количество:** минимум 15–20, лучше 40+ (движок берёт случайные и помнит последние 60 использованных, чтобы лента не повторялась).
- **Формат:** JPG или PNG, **вертикальные** (4:5 или 9:16), от 1080 px по короткой стороне. Обложка берётся только из вертикальных.
- **Размер файла:** до ~10 МБ (движок сам ужмёт до 1500 px).
- **Именование:** латиница/цифры без пробелов — например `trader_desk_01.jpg`, `portrait_02.jpg`. Файлы, начинающиеся с `_` или `.`, движок пропускает.

## Индекс (необязательно)

Без индекса движок берёт **все** JPG/PNG этой папки как вертикальные. Если хочешь фильтровать по тегам — создай `photos_index.json`:

```json
{
  "photos": [
    { "filename": "trader_desk_01.jpg", "format": "vertical", "outfit_set": "black_hoodie", "mood": "calm", "tags": ["терминал", "стакан"] }
  ]
}
```

Тогда для обложки берутся только записи с `"format": "vertical"`, а поле `outfit_set` не даёт поставить два кадра в одной одежде подряд.

## Служебные файлы

- `_photos_usage.json` — журнал последних использованных фото (создаёт `render.py` сам).

Путь к папке задан в `config/settings.yml → visuals.photos_dir`. Другую папку можно указать в `slides.json` полем `"photos_dir"`.
