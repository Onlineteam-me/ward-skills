# Montserrat — единственный шрифт Ward

Сюда кладётся `Montserrat[wght].ttf` (variable, кириллица, лицензия OFL) с Google Fonts.
Файл есть → `render.py` работает офлайн. Файла нет → движок подгружает шрифт с Google Fonts при рендере (нужен интернет). Если Montserrat с кириллицей не загрузился, рендер останавливается: подставлять другой шрифт нельзя.
