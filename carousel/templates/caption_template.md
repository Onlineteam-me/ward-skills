# Template — Подпись под пост (Ward)

## 🔴 Формат

**Первая строка = сразу суть** (продолжение хука обложки), без вступлений. **Последние строки = призыв «Подпишись, чтобы не потерять.» + дисклеймер «Не финансовая рекомендация.»**

Первая строка — главное место подписи: Instagram показывает в превью только её начало. Поэтому туда идёт смысл, а не призыв и не разделители (`— — —` не использовать — превью обрезается на нём).

## Структура

```
[Первое предложение контента — суть/поворот, продолжает хук обложки]

[3-5 строк — суть, без дублирования слайдов]

[1-2 строки — позиция бренда: честно, с минусами, без глянца]

[Мягкий вопрос аудитории — по желанию]

Подпишись, чтобы не потерять.

Не финансовая рекомендация.
```

## 🔴 Обязательный призыв (в КАЖДОЙ подписи, в конце)

Канонический текст (не переформулировать по смыслу):

> **Подпишись, чтобы не потерять.**

- Допустимы естественные вариации («Сохрани и подпишись, чтобы не потерять»), но без обещаний и без продвижения курса / Discord / KYC / подарков за комментарий (этап запуска).
- Канонический текст хранится в `materials/финальный_слайд.md` (единый источник).
- 🔴 **Дисклеймер «Не финансовая рекомендация.»** — последней строкой, всегда.

## Правила

- Первое слово контентной части — **НЕ «Я».** Начни с глагола, существительного, вопроса, факта.
- **Без хэштегов.**
- **Валюта — только `$` или USDT** (см. `knowledge/known_bugs.md` баг 4).
- 🔴 **Против теневого бана:** не писать «заработок / доход / быстрые деньги», никаких внешних ссылок.
- 🔴 **Никаких сумм-обещаний**, «без риска», «гарантированно». Конкурентов, брокеров и биржи не называем.
- Не дублируй текст со слайдов — добавь контекст или мета-комментарий.
- Позиция бренда — честная, спокойная, «свой трейдер за кофе», не «вода».
- Вопрос мягкий: «А ты с какого мифа начинал?», «Что было самым сложным на старте?».

## Пример наполнения

```
Стратегии без минусов не существует — и это первое, что стоит принять до первой сделки. Новичок меняет стратегию после 2–3 минусов и так ходит по кругу годами.

Профи отличается не тем, что не теряет. Он теряет мало и по плану: стоп стоит до входа, объём минимальный, каждая сделка — в журнале.

Результат даёт не одна сделка, а статистика на дистанции. Поэтому первые месяцы цель — не плюс на счёте, а не слить депозит и набрать эту статистику.

Скучно? Да. Но именно так выглядит профессия без глянца.

А ты сколько стратегий успел сменить?

Подпишись, чтобы не потерять.

Не финансовая рекомендация.
```
