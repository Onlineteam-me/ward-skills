# Workflow — Массовое создание каруселей (batch)

Используй когда нужно создать **2+ каруселей за один раз** из одного контента (например, «8 инсайдов → 8 каруселей»).

---

## Когда применять

- Один большой материал → несколько каруселей (1 инсайд = 1 карусель)
- Серия постов на одну тему (паттерны, кейсы, уроки)
- Контент-план на неделю/месяц — все JSON за одну сессию

Для одной карусели — используй обычный конвейер `workflows/render_format_A.md`.

---

## Принцип

```
Контент → Скрипт create_batch.py (все slides.json) → render.py × N
```

Ключевое: **весь авторинг (JSON + подписи) делается ДО рендера** — один Python-скрипт создаёт все папки/файлы, потом рендер запускается по очереди.

---

## Шаг 1 — Авторинг слайдов

Для каждой карусели составь `slides.json` по схеме `knowledge/slide_layouts.md`.

Типичная структура 10 слайдов (формат A):

| # | Макет | Назначение |
|---|---|---|
| 1 | `cover-photo` | Хук + фото лица бренда (папка пуста → типографика) |
| 2 | `poster` | Контекст / мостик |
| 3 | `photo-overlay` | Фото + первый кейс/тезис |
| 4 | `list` или `stat` | Список / цифра |
| 5 | `insight` | Основной инсайт |
| 6 | `quote` или `formula` | Цитата / формула |
| 7 | `formula` или `compare` | Применение |
| 8 | `poster` | Вывод для читателя |
| 9 | `photo-overlay` | Финальный тезис + фото |
| 10 | `cta` | Финал «Подпишись, чтобы не потерять» |

> Слайд 10 — ВСЕГДА `{"n":10,"layout":"cta"}`.  
> Движок сам верстает финальный слайд «Подпишись, чтобы не потерять» (`materials/финальный_слайд.md`).

---

## Шаг 2 — Подбор фото

Проще всего — `"photo":"auto"` во всех фото-слайдах: движок сам берёт рандом из `materials/фото_автора/` и помнит использованные между каруселями. Если нужен ручной рандом по индексу:

```bash
python3 - << 'EOF'
import json, random
idx = json.load(open("materials/фото_автора/photos_index.json"))   # запускать из папки скилла
vert = [p["filename"] for p in idx["photos"] if p.get("format") == "vertical"]
covers = random.sample(vert, 8)     # 8 обложек для 8 каруселей
print(covers)
EOF
```

Контентные фото (`photo-overlay` слайды) — аналогично `random.sample` из всего пула.

> 🟡 Папка фото пока заглушка — если она пуста, этот шаг пропускается: обложки и фото-слайды сверстаются типографикой (движок предупредит).

**Правила вариативности:**
- Разные `outfit_set` между каруселями (не одна одежда везде)
- Один кадр — один раз в карусели (движок проверяет сам, если `"photo":"auto"`)

## Шаг 3 — Генерация файлов

Используй шаблон `scripts/create_batch.py`:

```bash
# Скопируй шаблон в рабочую папку, задай OUTPUT_ROOT и заполни CAROUSELS
cp ~/.claude/skills/carousel/scripts/create_batch.py ./batch_$(date +%Y%m%d).py
# ... отредактируй ...
python3 ./batch_$(date +%Y%m%d).py
```

Или Claude может написать скрипт прямо в разговоре — заполнить `CAROUSELS` и запустить через Bash.

Результат:
```
<папка готовых каруселей>/
├── carousel_01/
│   ├── черновики/slides.json
│   └── подпись_под_пост.md
├── carousel_02/
│   ├── черновики/slides.json
│   └── подпись_под_пост.md
...
```

---

## Шаг 4 — Рендер

Скрипт выводит готовые команды. Запускай **последовательно** (не параллельно — Playwright не любит параллельные сессии):

```bash
VENV="<python с playwright из config/settings.yml>"
RENDER="$HOME/.claude/skills/carousel/scripts/render.py"
ROOT="<папка готовых каруселей>"

for name in carousel_01 carousel_02 carousel_03; do
  "$VENV" "$RENDER" "$ROOT/$name/черновики/slides.json" "$ROOT/$name"
  echo "✓ $name"
done
```

Или батчами по 2-4 через `&&`:

```bash
"$VENV" "$RENDER" "$ROOT/carousel_01/черновики/slides.json" "$ROOT/carousel_01" && \
"$VENV" "$RENDER" "$ROOT/carousel_02/черновики/slides.json" "$ROOT/carousel_02"
```

---

## Шаг 5 — Проверка

После каждого батча (или в конце) — читай **1-2 ключевых слайда** через `Read`:
- Обложка (01_cover.jpg) — фото + хук
- Один контентный (например, 07_formula.jpg) — типографика

**Лимит: ≤ 5 PNG за один ответ** (правило скилла).

---

## Шаг 6 — Подписи

Подписи пишутся прямо в скрипте (поле `"caption"`). Шаблон:

```
[Первое предложение — сразу суть, продолжает хук обложки]

[Контентная часть: раскрытие + позиция бренда + вопрос к аудитории]

Подпишись, чтобы не потерять.

Не финансовая рекомендация.
```

Канон подписи → `templates/caption_template.md`.

---

## Типовые ошибки

| Ошибка | Решение |
|---|---|
| Одно фото повторяется в разных каруселях | Делать `random.sample` по всем каруселям сразу, не по одной |
| Слайд 10 с кастомным текстом | Только `{"layout":"cta"}` — движок сам сверстает «Подпишись, чтобы не потерять» |
| Параллельный запуск render.py | Только последовательно |
| Новые фото без описания в `photos_index.json` | Дописать записи (`filename`, `format`, теги) или удалить индекс — движок возьмёт все фото папки |
| «⚠ папка фото автора пуста» / «нет клипов» | Это заглушки, не ошибка. Положить медиа — см. `materials/фото_автора/README.md`, `materials/video_bg/README.md` |
