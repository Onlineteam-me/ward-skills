# Workflow — Онбординг новой карусели

Когда пользователь даёт запрос (текст, ссылку, идею) — НЕ начинай сразу. Сначала собери 4 вопроса через `AskUserQuestion`.

---

## Блок 1 — три вопроса одним сообщением

### Вопрос 1 — «Источник контента?» (header: «Источник»)
- Текст / тезисы (уже в запросе) — *Тип input A*
- YouTube / статья / сайт (URL) — *Тип input B, я прочитаю через WebFetch*
- Идея / тема (опишу сам по контексту) — *Claude сам пишет с нуля*
- Скриншот / фото — *Анализирую визуально*

### Вопрос 2 — «Формат дизайна?» (header: «Формат»)
- **A — бренд личности** — фото лица бренда + видео-фон + типографика, фон cream-beige, шрифт Inter. Визуальные слоты (фото/видео) по таблице слотов. Для постов про личный путь / экспертность / философию. (См. `knowledge/visual_dna_format_A.md`)
- **B — Гибрид Higgsfield + HTML** — обложка (B1 Higgsfield-визуал ИЛИ B2 скриншот-источник) + остальные HTML/Playwright, фон с клеточкой, оранжевая закладка, чёрные карточки. Для постов со скринами / схемами / списками. (См. `knowledge/visual_dna_format_B.md`)
- **C — Ньюсджекинг (новость от себя)** — разбор злободневной новости/тренда от лица бренда: обложка с фото лица бренда + слайд-источник B2 (скрин + штамп «ИСТОЧНИК») + фото-каденция A + типографика. Когда у новости есть источник и нужна личная ассоциация. (См. `knowledge/format_C_recipe.md`)
- **Не уверен** — предложу на основе контента

> Если выбран формат A → визуальные слоты и сколько из них видео определяются по таблице в `visual_dna_format_A.md` (зависит от числа слайдов из Вопроса 3).
> Если выбран формат B → вид обложки: источник = тема/идея → **B1** (Higgsfield); источник = скриншот репо/статьи/сайта → **B2** (скриншот-источник). См. `workflows/build_cover.md`.
> Если выбран формат C → нужен источник новости (URL/скрин) для слайда-пруфа B2. Обложка = всегда фото лица бренда (папка пуста → типографская обложка). Слоты фото/видео — по таблице формата A. См. `knowledge/format_C_recipe.md`.

### Вопрос 3 — «Объём карусели?» (header: «Объём»)

🔴 **Жёсткий лимит — 10 слайдов** (API соцсетей для автопостинга, см. SKILL.md правило 1). Из них 9 контентных + 1 финальный слайд «Подпишись, чтобы не потерять» (правило 4). Вопрос — на сколько контентных:
- **9 контентных слайдов (стандарт, рекомендую)** — cover + 8 разворотов
- **7 контентных** — плотнее, для короткого тезиса (+1 пустой буфер на «дыхание»)
- Больше 9 контентных = **дроби на 2 карусели**, не нарушай лимит.

## Блок 2 — после ответов на блок 1

### Вопрос 4 — «Стиль хука для обложки?» (header: «Хук»)
- **И+С** — Интрига + Срочность (провокация, mystery)
- **В+П** — Выгода + Причастность (результат + для кого)
- **И+В** — Интрига + Выгода (любопытство + что получишь)
- **Придумай сам** (по контексту темы) — рекомендую если не уверены

См. полные формулы → `knowledge/hooks_formulas.md`
