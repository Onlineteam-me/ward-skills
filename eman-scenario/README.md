# eman-scenario — Сценарий Эман (версия для Ward)

Скилл для Claude Code: пишет сценарии коротких и длинных видео по деконструированной методике Имана Гаджи (жёсткий хук, парадокс уязвимого авторитета, авторские фреймворки, удержание, призыв с нулевым трением), но **голосом Ward**: «профессия без глянца», без роскоши и сумм, авторитет держится на честности, журнале и процессе. Реплики сразу в формате для AI-аватара (HeyGen), призыв везде один: «Подпишись, чтобы не потерять».

## Что внутри

- `SKILL.md` — оркестратор: жёсткие правила, карта файлов, конвейер.
- `knowledge/` — методика (матрица авторитета, хуки, структура, удержание, подача, фреймворки, триггеры, «холодный зритель», этика) + **`ward_filter.md`** (голос Ward, красные линии, единый призыв, формат HeyGen).
- `workflows/` — онбординг → план и апрув → сборка → сдача.
- `templates/` — шаблон сценария (с блоком «Текст для аватара»), банк хуков, паттерны названий фреймворков.
- `config/settings.yml` — платформы, тайминги, правила, параметры бренда.
- `SKILL_v1_monolith.bak.md` — архив старой версии, не используется.

## Установка

Скопируй папку в `~/.claude/skills/eman-scenario` или сделай симлинк:
```bash
ln -s "<путь к пакету>/ward-skills/eman-scenario" ~/.claude/skills/eman-scenario
```
Папку `_ward/` (голос бренда и ДНК аудитории) держи рядом со скиллом, на уровень выше: `<пакет>/ward-skills/_ward/`. При симлинке пути сохранятся. Если копируешь скилл отдельно — скопируй рядом и `_ward/`, либо скилл будет работать только по `knowledge/ward_filter.md` (он самодостаточен).

## Что настроить перед первым запуском

- **Ключи и токены не нужны.** Скилл работает только с текстом, без внешних сервисов и медиа.
- `config/settings.yml` → `output.folder` — куда сохранять сценарии (по умолчанию `Сценарии Эман/<название>/` в текущей рабочей папке).
- `config/settings.yml` → `defaults.voice` — `heygen_avatar` (по умолчанию) или `live`, если снимает живой человек.
- Реальную фактуру (годы практики, журнал, реальные ошибки ментора) скилл не выдумывает: оставляет плейсхолдеры `[…]` и список «Что подставить от себя». Заполни его перед съёмкой.

## Примеры команд

```
/eman-scenario
сценарий Эман: почему стратегии без минусов не существует, Reels 45 секунд
сценарий ролика для новичка Н-1 «застрял в найме», хук удар в боль
переупакуй тему «стакан вместо графика» в премиум, три пункта, под аватара
```

Скилл задаст пару вопросов (формат, хук, тема), прогонит тему через матрицу авторитета, покажет 5 хуков на выбор, после апрува соберёт сценарий и чистый текст для аватара.
