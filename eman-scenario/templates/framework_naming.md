# Паттерны названий авторских фреймворков

Цель — звучное название, которое делает банальный совет «дорогим IP». Механика обязательна (`knowledge/proprietary_frameworks.md`), иначе название = пустой шум.

---

## Рабочие паттерны (с примерами Гаджи)

| Паттерн | Формула | Примеры |
|---|---|---|
| **[Сущность] + Arbitrage** | использование разницы/рычага | Contractor Arbitrage |
| **[Состояние] Mode** | режим жёсткой дисциплины | Monk Mode |
| **[Действие] Detox** | сброс/очистка за период | Dopamine Detox |
| **[Глагол] to [Результат]** | трансформация | Dress to Elevate |
| **[Сущность] Matrix / Formula** | система оценки/расчёта | Money Making Matrix |
| **The [Прилагательное] [Существительное]** | именованный закон/принцип | The Frictionless Funnel |
| **[N]-[период] [действие]** | конкретный протокол | 90-Day Immersion |

## Для Ward — русские названия ремесла

Контент Ward на русском, тон «без глянца», а AI-аватар может неверно прочитать английское название. Поэтому для Ward:
- **По умолчанию — короткие русские названия правил ремесла:** «Правило первого стопа», «Скучная сессия», «Журнал до сделки», «Лимит дня», «Стакан, а не график».
- Английское название — только если оно привычно трейдерам (например, «Risk/Reward») и сразу объясняется словами.
- Паттерны выше работают и по-русски: «Режим [состояние]», «Правило [N] [чего]», «[N] дней [действие]» (в реплике N — словами).
- Название не должно намекать на деньги и роскошь («Матрица заработка», «Формула дохода» — нельзя).

---

## Правила нейминга

1. **Англ. звучит премиальнее** для рус. аудитории, но давай и рус. расшифровку в скобках при первом упоминании (холодный зритель).
2. **2-3 слова максимум** — длинное название не запоминается.
3. **Метафора статуса/рычага** в основе («arbitrage», «mode», «matrix») = ощущение скрытого механизма.
4. **Под каждое название — 3 конкретных правила/числа.** Без механики не выпускать.
5. **Не плодить** — на ролик 3 фреймворка хватает (= 3 пункта листикла-ядра).

---

## Анти-нейминг (так НЕ называть)

- ❌ Общие слова без рычага: «Система успеха», «Метод роста» — звучит как инфопродукт-пустышка.
- ❌ Аббревиатуры, которые надо расшифровывать дважды.
- ❌ Название = просто перевод банальности («Режим фокуса» вместо «Monk Mode»).
