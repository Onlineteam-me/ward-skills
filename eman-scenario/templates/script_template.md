# Шаблон вывода сценария

Структура финального сценария. Подставляй содержание, сохраняй секции и порядок.

---

```markdown
# Сценарий: [название ролика]
Платформа: [YouTube long / Reels / TikTok] · Хронометраж: [N мин/сек] · Хук: [стиль]

## 🎯 Матрица авторитета
- **Общий враг:** [миф ниши] → [reality check]
- **Авторитет:** флекс [плейсхолдер] + уязвимость [плейсхолдер]
- **Фреймворки:** [3 названия]
- **Протокол:** [название] — [3 правила]
- **Призыв:** «Подпишись, чтобы не потерять» + [причина сохранить]

## 📝 Сценарий

### Блок 1 — ХУК (0:00–1:00)
[тон: спокойный, уверенный, прямо в камеру, «свой трейдер за кофе»]
"[реплика хука: командный заход + удар в боль + авторитет вскользь + обещание]"
[b-roll: …] [пауза перед обещанием]

"[очеловечивание: предыстория / "мне повезло" / признание что путь не норма]"

### Блок 3 — ЛИСТИКЛ
**Пункт 1 — [Название фреймворка]**
"[полярное утверждение]. [механика для холодного зрителя]. [метафора]."
[триггер: флекс вскользь + приземление]

**Пункт 2 — …**
…

### Блок 4 — ПРОТОКОЛ + связка с продуктом
"[протокол навыка как входной билет в профессию: сессии, журнал, лимит потерь]"

### Mid-roll (середина)
"[мягкое напоминание подписаться / отсылка к следующему ролику серии]"

### Финал — CTA
"[фирменное прощание]. [условный призыв к комментам]. Подпишись, чтобы не потерять."
[на экране: Не финансовая рекомендация]

- **[Название]** — переупаковано из «[банальность]». Механика: [3 правила].

## 🎬 Пометки по съёмке/монтажу
- Локация: … · Ритм нарезки: … · Графика на экране: …

## 🔗 CTA
Подпишись, чтобы не потерять. [+ короткая причина сохранить]

- [ ] [реальный результат — цифра + срок]
- [ ] [реальная ошибка/провал]
- [ ] [реальный атрибут процесса: годы практики, журнал, число сессий]

[все реплики подряд, только произносимый текст: без ремарок, без «—» и «–», числа словами, без эмодзи, ссылок и скобок]
```

---

**Для Shorts/Reels** — сократить до: Хук (0-3 сек) → 1 фреймворк/1-3 пункта → 1 полярное утверждение → CTA. Секции «Матрица», «Фреймворки», «Что подставить», «Текст для аватара» оставить.
