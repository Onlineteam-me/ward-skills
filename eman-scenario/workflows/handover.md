# Workflow — Сдача сценария

## Куда сохранять

```
Сценарии Эман/<название>/      ← в рабочей папке пользователя (путь задаётся в config/settings.yml → output.folder)
├── сценарий.md              ← финальный сценарий (по script_template.md)
└── что_подставить.md        ← список плейсхолдеров (реальная фактура от пользователя)
```

Если сценариев под одну тему несколько (варианты A/B хука, long + Shorts версия) — клади их в ту же папку с понятными именами: `сценарий_long.md`, `сценарий_reels.md`.

## Правила сдачи

1. Пользователь должен сразу видеть **готовый сценарий**, а не черновики матрицы.
2. Все плейсхолдеры `[…]` из сценария — продублированы в `что_подставить.md` одним списком, чтобы было удобно заполнить.
3. Название папки — на русском, по теме ролика.
5. Если ролик идёт на AI-аватара — в `сценарий.md` есть чистый блок «Текст для аватара», который можно целиком вставить в HeyGen.
4. Не оставлять в корне папки временные заметки/прогоны матрицы — если нужны, в подпапку `черновики/`.

## После сдачи

- Кратко резюмируй: какой хук выбран, сколько пунктов, под какую платформу.
- Напомни про список «что подставить от себя» (реальные цифры/история).
- Предложи: собрать Shorts-версию из этого же сценария / прогнать через другой стиль хука.
