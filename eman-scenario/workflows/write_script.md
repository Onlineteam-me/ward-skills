# Workflow — Сборка финального сценария

После апрува хука и матрицы (`plan_and_approve.md`) — пиши полный сценарий по шаблону `templates/script_template.md`.

---

## Порядок сборки

1. **Возьми утверждённый хук** → разверни Блок 1 по `knowledge/hook_formulas.md` (4 элемента).
2. **Блок 2 (контекст)** → из Блока 2 матрицы (оговорка/очеловечивание). Помни: хук ≠ контекст.
3. **Листикл** → каждый пункт = название фреймворка (Блок 3) + полярное утверждение + механика + метафора. Чередуй приёмы удержания (`retention_techniques.md`).
4. **Вшей триггеры** (`psych_triggers.md`): флекс+демистификация парой, поляризация в острых пунктах.
5. **Блок 4 матрицы (протокол)** → отдельным сильным блоком ближе к финалу, свяжи с продуктом.
6. **Mid-roll** → мягкое напоминание подписаться или отсылка к следующему ролику серии (рекламу ресурсов для Ward не делаем).
7. **Финал/CTA** → фирменное прощание + призыв к комментам + «Подпишись, чтобы не потерять» (Блок 5 матрицы) + «Не финансовая рекомендация» на экране.
8. **Ремарки подачи** (`delivery_style.md`): `[тон]`, `[пауза]`, `[b-roll]`, `[графика на экране]` — отдельными строками, не внутри реплик.
9. **Фильтр Ward** (`knowledge/ward_filter.md`): убрать роскошь и суммы, проверить красные линии, привести реплики к формату HeyGen (без тире, числа словами), собрать чистый блок «Текст для аватара».

---

## 🔴 Обязательная проверка перед выдачей

1. Прогон по чек-листу **холодного зрителя** (`knowledge/cold_reader_principle.md`) — все 7 пунктов.
2. **Этика** (`knowledge/ethics.md`): нет выдуманных фактов, вся личная фактура = плейсхолдеры.
3. Нет рублей; в репликах нет «—» и «–», числа словами.
5. **Чек-лист фильтра Ward** (`knowledge/ward_filter.md`, раздел 5) — все пункты.
4. Флекс всегда в паре с приземлением.

---

## Что выдать пользователю (формат вывода)

По `templates/script_template.md`:
1. 🎯 Матрица авторитета (заполненная)
2. 📝 Полный сценарий по блокам (с ремарками и таймингами)
3. 🪝 3-5 альтернативных хуков
4. 🧱 Авторские фреймворки (название + механика)
5. 🎬 Пометки по съёмке/монтажу
6. 🔗 CTA: «Подпишись, чтобы не потерять» (+ вариация)
7. ✅ «Что подставить от себя» — список плейсхолдеров
8. 🎙 Текст для аватара — только реплики подряд, без ремарок, готово к вставке в HeyGen

Для Shorts/Reels — сжатая версия (см. `script_structure.md`).

→ Сдача: `workflows/handover.md`.
