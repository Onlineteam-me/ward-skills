- **Аудитория:** `knowledge/audience_dna.md` переписан по ДНК Ward (сегменты Н-1…Н-5, мифы новичков, страхи, красные линии); первоисточник — `_ward/` в пакете.

- **Заглушки:** ID базы/таблиц/вью Teable, адрес API, путь к медиа, аккаунт Zernio → `{{...}}` в `config/settings.yml`; описаны все нужные поля таблиц (`knowledge/pipeline_architecture.md`).

## История методики (до адаптации, кратко)
- **Изоляция контекста** — генерация контента через Agent() при батче >1 юнита (слайды «просачивались» между каруселями).
- **Окно свежести 100ч** — должно перекрывать паузу между прогонами пн/пт, иначе часть недели выпадает.
- **Reddit запрещён как источник** — скрины через прокси выглядели как подделка.
- **Заготовка ужесточена** — ≥300 симв, ≥3 цифры, ≥2 цитаты, контраст «было → стало»; без неё make_unit ABORT.
- **Silent-режим, дирижёр, строка целиком, новые юниты наверх, локальный путь к медиа** — правила #14–#18.
- **Слайд-источник обязателен** в каждой карусели; ссылка на источник переносится на юнит.
- **Каждый артефакт — через профильный Skill**; CTA — дословно из канона (после факапа с выдуманными цифрами и датами в инлайн-текстах).
- **Защита от зомби-записей** — лок 20ч, фильтр возраста 7 дней, дедуп URL, лимит 15 строк, гвард деградированного прогона.
- **v1.0** — тонкий оркестратор + knowledge/workflows/config/scripts; паттерн «Движок + JSON»; рубрика «Охват × Конверсия»; конвейер Отобранные → Единицы контента → Публикации; отклонённое → «Отсеяно (калибровка)».
