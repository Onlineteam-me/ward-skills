# Рубрика оценки — «Охват × Конверсия» (под ЦА Ward)

Это ядро отбора. Модель мышления одним предложением:

> **Беру крипто-новость, только если из неё выйдет единица контента, которая (1) соберёт охват у новичков И (2) приблизит зрителя к Ward — подписка + доверие «здесь честно объясняют и не разводят». Проваливается одна ось — не беру.**

Оценка не самоцель. Вопрос всегда: *«какую новость отобрать, чтобы из неё вышел ролик/карусель, которые новичок досмотрит, сохранит — и после которых подпишется на Ward».*

---

## Две оси (мысленно каждая 1–5)

### Ось A — ОХВАТ (досмотрят / сохранят / перешлют / прокомментируют)
- Есть **шок-факт**: крупная цифра ликвидаций, процент падения, число пострадавших от скама, дата вступления закона, плечо x50/x100 в истории слива?
- Ложится на хук-формулу **Ф1 «шок-факт → что это значит для тебя»** или **Ф2 «N минут / час назад…»** (срочная новость)? Если хук пишется за 10 секунд — ось сильная.
- Тема **живая прямо сейчас** (обсуждают в крипто-TikTok, Telegram, комментариях) — или мёртво-нишевая/техническая?
- Откликнется ли у новичка «это про мои деньги / про мою биржу / про мою страну», «надо сохранить, чтобы не попасть так же»?

### Ось Б — КОНВЕРСИЯ (двигает к Ward и к доверию)
- Бьёт в **боль, страх или миф новичка** из ДНК: ликвидация из-за плеча (миф 2), «трейдинг = казино» (миф 4), сигналы (миф 7), «деньги пропадут» при переводе, «меня разведут», «а это законно?». См. `knowledge/audience_dna.md`.
- Можно показать **механику, а не прогноз**: что произошло в стакане, почему сработали ликвидации, как стоп-лосс спас бы депозит, чем пирамида отличается от трейдинга?
- Попадает в конкретный **сегмент**: Н-4 (ликвидации, листинги, движения), Н-5 (скам, разводы, «гуру»), Н-3 (регулирование ЕС, налоги для эмигрантов), Н-1 (простое «что это значит для тебя»), Н-2 (дисциплина и риск)?
- Укрепляет позиционирование **«профессия без глянца»** — честно про риск, без хайпа?

## Итоговая Релевантность (связка осей) 1–10

| Балл | Условие | Действие |
|---|---|---|
| **9–10** | обе оси сильные — горячий шок-факт + прямой мост к мифу/страху новичка | брать первым |
| **7–8** | одна ось сильная, вторая средняя | брать (порог записи) |
| **5–6** | обе средние | пограничное — обычно не пишем |
| **1–4** | хоть одна ось мертва или нарушает красные линии | отсеять → «Отсеяно (калибровка)» |

Порог записи в «Отобранные новости» — **≥ 7** (см. `config/settings.yml → scoring.write_threshold`).

### Ориентиры по типам новостей (калибровка)
| Тип новости | Типичный балл | Почему |
|---|---|---|
| Массовые ликвидации / каскад после резкого движения | 8–10 | шок-цифра + прямой мост к мифу 2 и к стакану (Ф2 «N минут назад…») |
| Крупный скам / взлом / пирамида / фейковое приложение | 8–10 | страх «меня разведут» + отстройка Ward от казино (Н-5) |
| Решение биржи: ограничения для региона, KYC, заморозки, плечо | 7–9 | «это про мои деньги» + техническая тема входа; биржу в контенте не называем |
| Регулирование крипты в Украине / ЕС (закон, налоги, MiCA, позиция регулятора) | 7–9 | «а это законно?» + Н-3; только с фактами из официального источника |
| Листинг/делистинг монеты | 5–8 | охват есть, но легко скатиться в «залетай» — брать, только если есть угол механики/риска |
| История «слил на плече / по сигналам / у гуру» | 7–9 | миф 2 и 7 вживую, сегмент Н-5 |
| Курс BTC вырос/упал на N% без контекста | 4–6 | пустая цифра; берём, только если есть мост к ликвидациям или стакану |
| Прогнозы аналитиков, «BTC до $X» | 1–3 | прогноз цены = красная линия |

## 🔴 Жёсткие отсечки (сразу ≤4, не тащить)
- **Прогнозы цены**, «куда пойдёт рынок», «топ-монет на иксы», сигналы на вход.
- **Шилинг монет, ICO, пресейлы, аирдроп-фарминг, мемкоины «на иксы»** — даже как новость: из неё выйдет только реклама казино.
- **Инвестиционные продукты, ETF-потоки, корп-казначейства, M&A, раунды фондов** — без угла «что это значит для новичка».
- **Узко-технический блокчейн** (апгрейды протоколов, DeFi-механики, L2-архитектура), нерасжёвываемый для новичка.
- Новость, которую нельзя подать **без называния биржи/брокера/конкурента** как главного героя (реклама или антиреклама конкурента).
- Любая тема, где контент неизбежно уходит в «заработок / доход / быстрые деньги» (теневой бан + красная линия).
- Военная тема в эксплуатационном ключе.
- Нет пути ни к охвату, ни к Ward.

> Цифры и факты — только из источника. Не выдумывать суммы ликвидаций, проценты, номера законов, даты.

## Рекомендация формата (выводится из угла материала)

| Угол материала | Формат(ы) |
|---|---|
| Шок-факт + разбор «что это значит для тебя» (ликвидации, скам, закон) | **Карусель** |
| Срочная новость «N минут назад…» / что видел скальпер | **Видео (сам)** или **Видео (аватар)** |
| История слива / разоблачение схемы / реакция | **Видео (сам)** или **Тред** |
| Регулирование / налоги — подробный разбор с фактами | **Статья** + **Карусель** |
| Острый тезис / провокация против мифа | **Тред** |

Можно ставить несколько форматов. Финальный выбор форматов делает редактор в Teable (правит галочки при утверждении).

## Контроль качества прогона (см. `workflows/daily_parse.md`)
- Минимум `scoring.min_rows` строк (по умолчанию 8) — иначе плохо просмотрел.
- Хотя бы 2 материала 9–10 — «горячая» подача.
- Кластер 1 (рыночные события) представлен — иначе пропустил главное за период.
- Есть хотя бы одна новость про скам **или** регулирование — это самые доверительные темы для Ward.
- Не повторять то, что уже в таблице (дедуп по URL делает `fetch_sources.py`).
