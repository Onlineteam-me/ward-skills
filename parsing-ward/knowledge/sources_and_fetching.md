# Источники и добыча контента

Реестр живёт в Teable «Источники» (ID таблицы — `config/settings.yml → teable.tables.sources`, заглушка `{{TEABLE_TABLE_SOURCES}}`). Скилл читает только `Активен = true`.
Поля: **Название**, **Тип** (RSS / Сайт / Telegram / Twitter), **Адрес**, **Кластер** (приоритет), **Активен**. Подробная схема — `knowledge/pipeline_architecture.md`.

> 🔴 **Реестр пустой при передаче — его заполняет клиент.** Ниже примеры типов источников. **Ни один URL не гарантирован:** адреса RSS меняются, сайты закрываются. Каждый пометить «проверить» и перед добавлением открыть в браузере / прогнать `fetch_sources.py --no-dedup`.

## Кластеры = порядок приоритета парсинга
| Кл | Группа | Зачем |
|---|---|---|
| **1** | 🅰 Рыночные события | ликвидации, резкие движения, каскады — «N минут назад…» (Ф2) |
| **2** | 🅱 Решения бирж | листинги/делистинги, KYC, ограничения регионов, плечо, комиссии, заморозки |
| **3** | 🅲 Регулирование UA / ЕС | законы о виртуальных активах, налоги, НБУ/НКЦБФР, MiCA, ESMA |
| **4** | 🅳 Скам и безопасность | взломы, пирамиды, фейковые приложения, схемы P2P, задержания |
| **5** | 🅴 Крупные крипто-медиа | общий фон «что обсуждают» — добор, если кластеры 1–4 пустые |

## 🔴 Reddit — не использовать как источник
Reddit блокирует ботов: RSS отдаёт мусор, скрины источника получаются через сторонние прокси и выглядят как подделка. **НЕ добавлять Reddit-источники** ни в таблицу, ни инлайн. Если reddit-тема попала в «Отобранные» другим путём — контент подавать «от себя» без слайда-скрина Reddit (фолбэк: первоисточник новости или другое СМИ).

## Чем тянет движок `fetch_sources.py`
- **RSS** → XML-парс (RSS и Atom), окно свежести из `config.fetch.freshness_hours`, до `max_per_source` позиций.
- **Сайт** → универсальный HTML-парс: ищет ссылки с путями `/news/`, `/announcement`, `/press`, `/article`, `/blog/` и т.п. и текстом-заголовком ≥20 символов. Дату со страницы не берёт (`date: ""`) — модель проверяет дату по самому материалу.
- **Сайт из `fetch.js_sites`** (страницы, которые рисует JavaScript: агрегаторы ликвидаций, объявления бирж) → скрипт отдаёт `[]`. Добирать через **WebSearch** с `allowed_domains` (только материалы за последние 2–3 дня).
- **Telegram / Twitter** → скрипт не парсит (хрупко). Только вручную или через WebSearch.
- Дедуп против URL из «Отобранные новости» + «Отсеяно» + «Единицы контента» (`teable.py seen`).
- Ретрай на 429 + пауза 0.7с между источниками.

## 🔴 Известные капризы (не паниковать)
- Некоторые медиа периодически отдают не-XML → ParseError. Фолбэк: WebSearch по домену.
- 403 без User-Agent — UA уже в конфиге.
- 429 (троттлинг) — ретрай встроен; если всё равно упал — пропустить, не блокироваться.
- Страницы регуляторов иногда меняют вёрстку — универсальный парсер найдёт 0 ссылок. Тогда добрать WebSearch или дописать ветку в `fetch_sources.py:fetch_site()`.
- Источник не отдался → не блокируемся, продолжаем. В конце отчёта — блок «⚠ не удалось забрать».

## Добавить/убрать источник
Правка в Teable «Источники» (Активен / Адрес / Кластер) или через `teable.py add_source / toggle_source / del_source` — код менять не надо. Новый веб-тип со сложным HTML → дописать ветку в `fetch_sources.py:fetch_site()` или добавить домен в `fetch.js_sites` и добирать WebSearch.
