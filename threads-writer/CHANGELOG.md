# CHANGELOG — threads-writer

## v1.7.0-ward — 2026-10-27 — Адаптация для Ward

Адаптация для Ward: скилл переведён на голос и аудиторию Ward (украинский криптоброкер для скальперов, «профессия без глянца»). Методика (правила, гейты, workflows, скоринг, regex-veto, шаблоны) сохранена полностью.

- **`knowledge/voice.md`** — переписан как голос Ward: «свой трейдер за кофе», спокойно и честно, минусы наравне с плюсами, красные линии ToV, язык — русский, обращение на «ты».
- **`knowledge/audience_dna.md`** — новая выжимка ДНК новичков Ward в прежнем формате: сегменты Н-1…Н-5, боли, страхи, мифы с «правдой Ward», дословный язык, слова доверия и недоверия, триггеры решения, запреты. Полные документы — ссылки на `../_ward/`.
- **Удалены** прежние полные ДНК/позиционирование (ссылки `materials/full_dna_*.md`, `materials/full_positioning.md` заменены ссылками на `../_ward/ДНК клиента — новички.md` и `../_ward/Голос бренда Ward (ToV).md`), бэкап монолита `SKILL_v0.1_monolith.bak.md` и скрины провалов (медиа в пакет не входят; тексты провалов есть в `examples/anti_refs/anti_refs.md`).
- **CTA**: прежний призыв с кодовым словом заменён на канонический «Подпишись, чтобы не потерять». Тип поста `cta-magnet` переименован в `cta-subscribe` (`knowledge/post_types.md`, `SKILL.md`).
- **Ссылки**: добавлен переключатель `links.external_links_allowed: false` в `config/settings.yml` (красная линия Ward против теневого бана). Правила URL по типам постов сохранены как методика на случай, если ссылки разрешат.
- **Красные линии Ward** встроены в чек-листы и regex-veto (`workflows/two_pass_humanize.md` V9–V11, `templates/post_format.md`): без сумм-обещаний, «без риска», слов «доход / заработок / быстрые деньги», названий бирж и брокеров, внешних ссылок. Валюта — только `$` / `USDT`.
- **Примеры**: `examples/viral_refs/ward_refs.md` — 5 калибровочных постов Ward; `examples/anti_refs/anti_refs.md` — классические провалы А/Б/В + тейлы ленты и красные линии на материале Ward.
- **Хуки, холодный читатель, фактчек** (`hook_bank.md`, `cold_reader.md`, `fact_check.md`) — примеры переведены на трейдинговую тематику; аббревиатуры — крипто-словарь (KYC, P2P, сети, PnL, стоп-лосс).
- **Пути**: абсолютные пути и личные аккаунты убраны; `config/settings.yml` → `paths`, `SKILL.md` → «Установка / синк» — относительно `~/.claude/skills/threads-writer`.
- **`README.md`** — новый: установка, что настроить, примеры команд.

## История методики (кратко)

- **v1.6.0** — тейлы ленты: бан пустых связок-подводок, обязательный разброс длины в пачке, «пост для своих» (`ai_anti_patterns.md` §25–27), Тест 4 «инсайт, а не вырезка» для видео и интервью.
- **v1.5.0** — ДНК аудитории как обязательное чтение перед генерацией; типы постов и правила URL под каждый (`post_types.md`); потолки количества уменьшены (короткая новость 2, лонгрид 3); финальный regex-veto в two-pass humanize.
- **v1.4.0** — ссылки на источники для постов, называющих конкретный инструмент; реактивные зачины (хук тип 8), не больше 1–2 на набор.
- **v1.3.0** — гейт источника-сироты (3 теста: названный субъект / заякоренное число / своя завязка), «лучше меньше, но сильных» (количество = потолок), банк anti_refs.
- **v1.2.1** — бан затёртого зачина «Пока ты думаешь…» и родственных мотивационных шаблонов.
- **v1.2.0** — Pool-режим (атомарные посты) как дефолт: источник = топливо, матрица разнообразия, shuffle-safety, бан связок треда.
- **v1.1.1** — длинное тире: zero tolerance в финале, таблица замен.
- **v1.1.0** — Threads-нативность (reply-velocity, ultra-short, conversation starters), режим «06 · Несовершенство», anti-template variety, reply-bait в скоринге, банк виральных референсов.
- **v1.0.0** — Pro-архитектура: тонкий оркестратор + модули, two-pass humanize по 24 AI-анти-паттернам (адаптация [blader/humanizer](https://github.com/blader/humanizer), MIT).
- **v0.1.0** — MVP: входы текст / URL / YouTube / аудио, режимы генерации, скоринг.
