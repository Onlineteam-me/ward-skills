# Threads Writer (версия для Ward)

Скилл для Claude Code: превращает любой источник (текст, тезисы, ссылку на статью, YouTube/TikTok-видео, аудио, подборку новостей) в пачку атомарных постов для Threads — **в голосе Ward** («профессия без глянца», «свой трейдер за кофе»), без AI-душка и без нарушений красных линий бренда.

Внутри: 6 режимов генерации, банк хуков, гейт «поста-сироты» (пост понятен без исходника), two-pass humanize по 27 AI-анти-паттернам, скоринг по 6 осям, финальный regex-veto (тире, обещания дохода, ссылки, названия бирж). Цифры — только из источника. Количество постов адаптивное: лучше меньше, но сильных.

## Установка

Скопируйте папку скилла в `~/.claude/skills/` или сделайте симлинк:

```bash
# вариант 1 — копия
cp -R threads-writer ~/.claude/skills/threads-writer

# вариант 2 — симлинк на папку пакета
ln -s "<путь к пакету>/threads-writer" ~/.claude/skills/threads-writer
```

🔴 Скилл ссылается на общие документы бренда в `../_ward/` (на уровень выше папки скилла): `Голос бренда Ward (ToV).md` и `ДНК клиента — новички.md`. При симлинке на папку пакета это работает само. Если копируете скилл отдельно — положите папку `_ward/` рядом (`~/.claude/skills/_ward/`) или поправьте пути в `knowledge/audience_dna.md`, `knowledge/voice.md` и `config/settings.yml` → `brand`.

Опционально — slash-команда: `cp ~/.claude/skills/threads-writer/SKILL.md ~/.claude/commands/threads-writer.md`.

## Что настроить перед первым запуском

1. **Ключей и токенов скиллу не нужно.** Файла `config/secrets.yml` нет. Публикация в Threads делается отдельно (например, скиллом `zernio-posting` со своими настройками).
2. **`config/settings.yml`** — проверить:
   - `links.external_links_allowed: false` — внешних ссылок в постах нет (красная линия Ward). Поставьте `true`, только если бренд разрешит ссылки.
   - `brand.cta` — призыв «Подпишись, чтобы не потерять». Поменяйте, когда начнёте продвигать курс/Discord.
   - `brand.language` и `transcription.language` — `ru`. Для украинских постов поставьте `uk` и поправьте раздел «Язык» в `knowledge/voice.md`.
   - потолки количества постов (`posts_count_ceiling_*`).
3. **Заглушек `{{...}}` в этом скилле нет** — ID баз и аккаунтов он не использует.
4. **Медиа-папок нет.** Скилл работает только с текстом. Папки примеров — текстовые:
   - `examples/viral_refs/` — уже есть `ward_refs.md` (5 калибровочных постов). Добавляйте сюда реальные залетевшие посты Ward — голос станет точнее. Если папка пустая, скилл не падает, просто пишет по `knowledge/voice.md`.
   - `examples/anti_refs/` — провалы «как нельзя». Тоже можно пополнять.
5. **Для видео и аудио** (необязательно) нужны `ffmpeg`, `yt-dlp` и `uvx` + `mlx-whisper` (Apple Silicon). Без них скилл работает с текстом и ссылками на статьи.

## Примеры команд

```
/threads-writer
<вставьте текст, тезисы или ссылку>
```

```
сделай посты в тредс из этого видео: https://www.tiktok.com/@.../video/...
```

```
нарежь на тредс эту статью, сегмент Н-4 (крипто-хомяки), максимум 3 поста
```

```
перепиши хук второго поста — дай 5 вариантов
```

Модификаторы: «Сделай провокационнее», «Короче — 3 строки максимум», «Режим Несовершенство», «Добавь curiosity gap», «Сделай тред» (связная ветка вместо атомарных постов). Полный список — `knowledge/modes.md`.

## Структура

```
threads-writer/
├── SKILL.md                # оркестратор: жёсткие правила, карта, конвейер
├── README.md               # этот файл
├── CHANGELOG.md            # история версий
├── config/settings.yml     # параметры: потолки, формат, скоринг, бренд, ссылки
├── knowledge/              # голос Ward, ДНК аудитории, режимы, хуки, анти-паттерны, гейты
├── workflows/              # извлечение источника, two-pass humanize, скоринг и отбор
├── templates/post_format.md
└── examples/               # viral_refs (эталоны тона), anti_refs (провалы)
```

Методика two-pass humanize основана на [blader/humanizer](https://github.com/blader/humanizer) (MIT) и Wikipedia: Signs of AI writing, адаптирована под русский язык и формат Threads.
