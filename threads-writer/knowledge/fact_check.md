# Цифры и факты

## 🔴 Главное правило

**Цифры — только из источника.** Никогда не выдумывать:
- статистику, проценты, доли
- суммы денег, цены, курсы
- даты, годы, кварталы
- количества (подписчиков, фирм, людей)

## Алгоритм

1. **Сначала собрать «банк фактов»** из источника (см. `workflows/extract_source.md`). Это список конкретных цифр с пометкой «откуда».
2. **Посты лепить только из банка.** Если для фразы нужна цифра, которой в банке нет — два варианта:
   - убрать цифру, перефразировать без неё;
   - уточнить через WebSearch/WebFetch, добавить **реальный** источник.
3. **Никогда** не вписывать «правдоподобную» цифру по памяти/ощущению.

## Атрибуция в посте

- Короткая отсылка к источнику словами в самом посте, если цифра спорная: «по биржевой статистике ликвидаций за сутки», «в исследовании регулятора, апрель 2026».
- Без URL (Ward: внешних ссылок нет, см. `config/settings.yml` → `links`). Биржи и брокеров по имени не называем.
- Без «по данным ряда исследований» (это AI-тейл, см. `ai_anti_patterns.md` §4).

## Аббревиатуры — переводить

Профессиональные сокращения → массовый язык:
- KYC → «проверка личности на бирже»
- P2P → «покупка напрямую у другого человека»
- TRC20 / BEP20 / ERC20 → «сеть для перевода» (название сети оставить, если пост про выбор сети)
- PnL → «результат по сделкам»
- SL / TP → «стоп-лосс» / «тейк-профит» (при первом упоминании объяснить на пальцах)
- DCA, ROI, R:R → простыми словами
- Стакан, плотность, спред, ликвидация — термины ремесла: оставлять, но новичку объяснять в одной фразе

## Валюта

🔴 **Только `$` или `USDT`** (ToV Ward). Рубли (`₽` / `руб`) запрещены. Можно и без валюты, если не критично.

🔴 **Цифра ≠ обещание.** Никаких сумм дохода, «заработал за N дней», «$X в день». Цифры результата — только с контекстом риска и минусов, и только из источника.
