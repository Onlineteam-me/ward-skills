# Workflow — Two-pass humanize (адаптация humanizer)

**Главное наследие [blader/humanizer](https://github.com/blader/humanizer):** не пытаться написать «идеально человечный» пост с первого раза. Делать в два прохода: **черновик → AI-аудит → финал.**

Применять **всегда** перед выдачей пользователю. Это разница между «нормально» и «не пахнет AI».

---

## Шаг 1. Черновик (draft)

Сгенерировать посты по выбранному режиму (см. `knowledge/modes.md`). Использовать голос автора (`knowledge/voice.md`), банк хуков (`knowledge/hook_bank.md`) и правила «холодного читателя» (`knowledge/cold_reader.md`).

Цифры — только из банка фактов (см. `knowledge/fact_check.md`).

## Шаг 2. AI-аудит (звено-«киллер»)

Задать себе **вслух**: **«Что в этих постах всё ещё выдаёт AI?»** Пройтись глазами по черновику с открытым `knowledge/ai_anti_patterns.md` рядом.

Найти **кластеры** тейлов (не одиночные). Конкретно проверять:

- [ ] **🔴 §12 Длинное тире — ZERO в финальном посте.** Не 1–2, а ноль. Любое `—` → проверить по таблице замен в `ai_anti_patterns.md` §12. Оставить только если без тире фраза реально ломается (редкий случай). **В режиме Несовершенство правило усиливается, не ослабляется.**
- [ ] **§1 Раздувание значимости** («знаковый», «играет ключевую роль», «отражает тенденции») — есть?
- [ ] **§2 «-ующий/-ающий» обороты** для «глубины» — есть?
- [ ] **§3 Промо-лексика** («уникальный», «впечатляющий», «по-настоящему», «инновационный») — есть?
- [ ] **§4 «Эксперты считают» / «исследования показывают»** без конкретики — есть?
- [ ] **§6 AI-словарь** («ключевой», «погружаемся», «ландшафт», «синергия», «эволюция») — есть? Сколько на пост?
- [ ] **§7 Уход от «есть/это»** («представляет собой», «является», «служит») — есть?
- [ ] **§8 Отрицательные параллелизмы** («не просто X, а Y») — есть? **Это самый частый тейл.**
- [ ] **§9 Правило трёх** в одной фразе — есть?
- [ ] **§11 Ложные диапазоны «от X до Y»** — есть?
- [ ] **§14 Списки-заголовки с двоеточиями** — есть? (В Threads вообще лишнее.)
- [ ] **§16 ChatGPT-вежливость** («надеюсь, поможет», «отличный вопрос») — есть? **Должно быть НЕТЬ.**
- [ ] **§19 Филлеры** («в современном мире», «стоит отметить», «не секрет, что») — есть?
- [ ] **§20 Хеджирование** («возможно, в каком-то смысле, при определённых условиях») — есть?
- [ ] **§21 Дежурный позитивный финал** («будущее выглядит ярко») — есть?
- [ ] **§22 «По сути, главный вопрос…»** — есть?
- [ ] **§23 Сигналинг** («давайте разберёмся», «погружаемся») — есть? **Должно быть НЕТЬ.**
- [ ] **Голос автора** (`voice.md`) — звучит как Ward («свой трейдер за кофе») или как «обобщённый эксперт»? Чувствуется личная позиция?
- [ ] **Холодный читатель** (`cold_reader.md`) — каждый пост понятен с нуля?

Записать **коротким списком** найденные тейлы (для себя, не показывать пользователю по умолчанию).

## Шаг 3. Финальный rewrite

Пройтись по списку и **переписать**, а не «доработать». Замены:

- Длинное тире → точка / запятая / двоеточие.
- «представляет собой» → «это» / «—».
- «ключевой» / «важнейший» → выкинуть или конкретное слово.
- «не просто X, а Y» → одна сильная фраза.
- «исследования показывают» → конкретный источник или вырезать.
- Промо-прилагательное → конкретный глагол / факт.

**После переписывания** — пробежать ещё раз глазами на:
- 🔴 `—` (длинное тире): финальный поиск по тексту, **должно быть 0**. Любое найденное заменить по таблице из `ai_anti_patterns.md` §12.
- ChatGPT-вежливость: должно быть 0.
- Сигналинг («давайте разберёмся»): должно быть 0.

## Шаг 3.5. 🔴 ФИНАЛЬНЫЙ REGEX-VETO (жёсткий)

**История:** правило «0 длинных тире» существует с v1.0. Реальность (реальные прогоны скилла до v1.5): **36 из 37 тредов имели `—` в тексте**. То есть проверка в шагах 2-3 регулярно проваливалась. Значит нужен **финальный автомат-контроль перед выдачей**.

Перед возвратом ответа пользователю — прогнать финальный текст ВСЕХ постов через regex-проверки. Если хоть один пост нарушает — **вернуть в шаг 3 rewrite конкретный пост, не отдавать всю пачку.**

**Список regex-veto:**

| # | Regex | Правило | Действие |
|---|---|---|---|
| V1 | `—` | 0 длинных тире | Заменить на точку/двоеточие/запятую (`ai_anti_patterns.md` §12) → rewrite поста |
| V2 | `(?i)^(перв\|втор\|трет\|четверт\|пят)(ая\|ое\|ый\|ий)\s+(тезис\|принцип\|правил\|вывод\|мысл\|инсайт)` | Нумерация тезисов = связка треда | Rewrite (`atomic_posts.md` бан-лист) |
| V3 | `(?i)как я (писал\|говорил) выше` | Ссылка на несуществующий пост | Rewrite |
| V4 | `(?i)а теперь главное\|продолжа(я\|ю) мысль\|вот в чём (капкан\|дело\|соль)` | Связка треда | Rewrite |
| V5 | `(?i)\b(прорыв\|трансформация\|квантовый скачок\|успешный успех\|секретн(ая\|ую) (стратеги\|связк\|формул))` | Инфобиз-маркер (`audience_dna.md` запрещённое) | Rewrite |
| V6 | `(?i)гарантиру[ею]\s+(доход\|результат)\|(100К\|10K)\s+за\s+(месяц\|30 дней)` | Обещание гарантированного дохода | Rewrite |
| V7 | `(?i)(₽\|\bруб)` | Рубли | Заменить на `$` / `USDT` / без валюты |
| V8 | `(?i)давайте разберёмся\|надеюсь, поможет\|отличный вопрос` | ChatGPT-вежливость/сигналинг | Удалить фразу |
| V9 | `(?i)\b(доход\|заработ\|быстрые деньги\|без риска\|гарантированн\|пассивн(ый\|ого) доход\|финансов(ая\|ую) свобод)` | Красная линия Ward: обещания и стоп-слова теневого бана | Rewrite без обещания и без стоп-слова |
| V10 | `https?://` | Внешняя ссылка при `links.external_links_allowed: false` | Удалить URL, назвать источник словами |
| V11 | `(?i)\b(binance\|bybit\|okx\|bitget\|mexc\|pocket option)\b` | Названия бирж/брокеров/конкурентов (ToV Ward) | Заменить на «биржа», «брокер», «платформа с опционами» |

**Реализация в голове (или скриптом):** пробежать финальный текст ВСЕХ постов, найти все совпадения. Если найдено — **вернуться в шаг 3 и переписать проблемный пост**, а не «убрать одно слово». Только когда все regex вернули 0 совпадений — **ТОЛЬКО ТОГДА** переход к Шагу 4.

⚠️ **Правило veto:** если после 2 попыток rewrite пост всё равно не проходит — **выкинуть его**, отдать n-1 постов. Лучше 2 чистых, чем 3 с провалами.

## Шаг 4. Выдача

По умолчанию показывать пользователю **только финальную версию.** Черновик и список тейлов — внутренняя кухня.

Если пользователь попросил «покажи разбор» / «что было не так» — отдать draft + audit-список + final, как делает оригинальный humanizer.

---

## Анти-паттерны самого процесса

- ❌ **Пропустить аудит.** «И так нормально» — почти всегда AI-душок просочился.
- ❌ **Дорабатывать вместо переписывать.** Заменить 1 тейл и оставить остальные — пост всё равно пахнет.
- ❌ **Вычистить ВСЕ тейлы до стерильности.** Цель — звучать как человек, а не как «правильный текст». Если убрал AI-душок, но текст стал плоским — добавь обратно живые приёмы (см. `voice.md`).
