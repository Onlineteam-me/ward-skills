# CHANGELOG — ward-content-factory

## 1.0.0 — 2026-10-27
Первая версия оркестратора.
- Тонкий `SKILL.md` (11 жёстких правил, карта-роутинг, конвейер) + модули `knowledge/`, `workflows/`, `templates/`.
- Мастер настройки «настрой завод»: проверка Teable, Zernio, HeyGen, Higgsfield (MCP), соседних скиллов; один файл ключей `config/secrets.yml`.
- Статусная модель: Идея → Пуля → Тексты готовы → Медиа готовы → На проверке → Запланировано → Опубликовано (+ Отклонено), поля на каждом шаге.
- Команды: «сделай контент на неделю», «доведи пулю №N», «что в работе», «новые идеи из новостей».
- Исполнители запускаются субагентами по шаблону брифа с обязательным чтением всех модулей скилла и отчётом о применённых правилах; карусели — по одной на агента.
- Пресеты 4 AI-аватаров HeyGen, сетка публикаций, дизайн-код Ward для Higgsfield (`../_ward/Дизайн-код Ward.md`).
- QC-гейт по красным линиям ToV: движок `scripts/factory.py qc`, проверен на 22 пулях базы клиента.
- `factory.py infer` — перевод старых статусов (Идея / В работе / Готово) на новую модель по заполненным полям.
