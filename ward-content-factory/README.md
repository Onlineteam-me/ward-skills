# Контент-завод Ward — оркестратор

Скилл для Claude (Claude Code / Claude Desktop), который дирижирует остальными скиллами пакета и ведёт каждую единицу контента по статусам в Teable — от идеи до публикации.

## Как устроен пакет

```
ward-skills/
├── ward-content-factory/   ← этот скилл: настройка, статусы, команды, проверка
├── parsing-ward/           ← новости по расписанию → своя таблица
├── threads-writer/         ← исполнитель: Threads
├── eman-scenario/          ← исполнитель: сценарии для аватаров
├── carousel/               ← исполнитель: тексты и рендер каруселей
├── zernio-posting/         ← исполнитель: публикация
└── _ward/                  ← ДНК, голос бренда, дизайн-код
```

Оркестратор ищет соседей по относительным путям (`config/settings.yml → executors`), поэтому папки должны лежать рядом, как выше.

## Установка (один раз)

1. Из корня пакета запустить `bash install.sh` — он сделает симлинки всех скиллов и `_ward` в `~/.claude/skills/`.
2. Скопировать `config/secrets.example.yml` → `config/secrets.yml` и вписать ключи Teable, Zernio, HeyGen.
3. Подключить Higgsfield как MCP-сервер в Claude (настройки Claude → Connectors / MCP).
4. Сказать Claude: **«настрой завод»**. Мастер проверит каждое подключение и скажет, что вписать в `config/settings.yml` (ID базы и таблиц, accountId площадок, ID аватаров и голосов HeyGen). Подробно — `workflows/setup.md`.

Нужен только Python 3 (стандартная библиотека). Если стоит PyYAML — будет использован, нет — встроенный парсер.

## Команды

| Сказать Claude | Что произойдёт |
|---|---|
| «настрой завод» | проверка всех подключений, список того, чего не хватает |
| «сделай контент на неделю» (можно «на 7 пуль») | идеи → пули → тексты → медиа → проверка → план публикаций |
| «доведи пулю №12» | одна пуля до следующего готового состояния (или до конца) |
| «что в работе» | сводка: сколько пуль на каком статусе и что делать дальше |
| «новые идеи из новостей» | свежие утверждённые новости parsing-ward → пули со статусом «Идея» |

## Что настроить в Teable

В таблице «Единицы контента» поле **Статус** должно содержать варианты: Идея, Пуля, Тексты готовы, Медиа готовы, На проверке, Запланировано, Опубликовано, Отклонено. Рекомендуемые новые поля: **Аватар**, **Папка с медиа**, **QC-отчёт**. В «Адаптациях» к статусу стоит добавить вариант **Запланировано**. Мастер настройки покажет, чего не хватает, и может добавить это сам после вашего «ок». Схема — `knowledge/teable_schema.md`.

## Безопасность

- `config/secrets.yml` в `.gitignore` — не коммитить.
- Скилл ничего не публикует без проверки (QC-гейт) и вашего «ок».
- Фото аватаров и логотип в пакет не входят — положите свои (см. `materials/avatars/README.md` и `../_ward/логотип/README.md`).
