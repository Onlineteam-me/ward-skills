# Стандарт выдачи исполнителей — формат ячеек Teable

Каждая длинная ячейка с готовым текстом («Сценарий HeyGen», «Threads-посты», «Текст карусели») устроена одинаково: **инструкция для человека → блоки контента между маркерами → служебные строки**. Цель — редактор копирует ровно то, что нужно, и ничего лишнего не уходит в публикацию. QC-движок опирается на эти маркеры: нет маркеров — 🔴.

## Общие правила

1. Первая часть — блок `═══ ИНСТРУКЦИЯ ═══ … ═══════════════════`: что это, что копировать, длина/лимиты, язык, где дисклеймер.
2. Контент — между маркерами `▼ … ▼` (начало) и `▲ … ▲` (конец). Всё между ними копируется целиком, без правок.
3. Служебные строки (подсчёт символов, скоринг, «Зачем», «Каркас») — **вне** маркеров и помечены, что их не копировать.
4. Текст — по-русски. Никаких ссылок, рублей, названий бирж (см. `qc_gate.md`).
5. Одна ячейка = одна пуля. Не склеивать несколько пуль в одну ячейку.

## «Сценарий HeyGen» (исполнитель eman-scenario)

```
═══ ИНСТРУКЦИЯ ═══
Что это: сценарий для озвучки AI-аватаром в HeyGen. Один ролик 9:16.
Что копировать в HeyGen: только текст между линиями «▼ ТЕКСТ ДЛЯ ОЗВУЧКИ ▼» и «▲ КОНЕЦ ТЕКСТА ▲», целиком.
Длина: ~N сек, M слов. Язык: русский. Аватар/тон: <пресет из avatar_presets.md>, темп, паузы; скорость голоса 1.0.
═══════════════════
▼ ТЕКСТ ДЛЯ ОЗВУЧКИ ▼
<только произносимый текст: без тире «—», числа словами, без эмодзи, ссылок и скобок>
…
Подпишись, чтобы не потерять.
▲ КОНЕЦ ТЕКСТА ▲

─── ДЛЯ МОНТАЖА (не озвучивать) ───
Таймкоды и визуал: 0–6 с — …; 6–13 с — …
Текст-хук на экране (первые 2 сек): «…»
Подпись к публикации: <текст подписи; заканчивается «Подпишись, чтобы не потерять.» и «Не финансовая рекомендация.»>
Субтитры: по словам, крупно. На экране и в подписи не использовать слова «заработок», «доход», «быстрые деньги»; без ссылок.
Каркас (eman-scenario, Shorts): хук … → … → подписка.
Проверить/подставить: — (или что именно)
```

Что проверяет QC: есть блок озвучки; в озвучке есть «подпишись, чтобы не потерять»; в подписи есть призыв и дисклеймер; в озвучке нет цифр (🟡), тире (🟡), ссылок/эмодзи (🔴).

## «Threads-посты» (исполнитель threads-writer)

```
═══ ИНСТРУКЦИЯ ═══
Что это: N ОТДЕЛЬНЫХ постов для Threads. Каждый публикуется отдельно, в разные дни/время. Это НЕ тред.
Что копировать: только текст между «▼ ПОСТ k ▼» и «▲ КОНЕЦ ПОСТА k ▲». Это ровно одна публикация (лимит Threads 500 символов).
Служебная строка под постом (Символов / Тип / Режим / Скоринг / Зачем): НЕ копировать.
Язык: русский. Дисклеймер «Не финансовая рекомендация» стоит в профиле, в пост не вставлять.
Скоринг по скиллу threads-writer: 6 осей × 5 = 30, проходной порог 18.
═══════════════════

▼ ПОСТ 1 из N ▼   (тип: отдельный пост)
<текст поста>
▲ КОНЕЦ ПОСТА 1 ▲
Символов: 403  ·  Тип: …  ·  Режим скилла: …  ·  Скоринг: 28/30 (…)  ·  Зачем: …
```

Если это тред (связанные посты подряд) — в инструкции прямо «Это ТРЕД: публиковать подряд ответами», маркеры те же. QC: маркеры есть, каждый пост ≤ 500 символов.

## «Текст карусели» (исполнитель carousel)

```
═══ ИНСТРУКЦИЯ ═══
Что это: текст ОДНОЙ карусели Instagram из N слайдов (формат 4:5). Каждый блок «СЛАЙД k» = одна картинка.
На слайде: «Заголовок» — крупно, «Текст» — мелко (может отсутствовать). «Визуал» — подсказка дизайнеру, на слайд НЕ пишется.
Подпись к посту — в конце, отдельно (копируется в поле описания публикации).
Язык: русский.
═══════════════════

▼ СЛАЙД 1 из 10 — обложка ▼
Заголовок: …
Текст: …
Визуал: …
▲

▼ СЛАЙД 10 из 10 — финал / CTA ▼
Заголовок: Подпишись, чтобы не потерять
Текст: … Не финансовая рекомендация.
Визуал: финальный слайд в стиле бренда Ward …
▲

═══ ПОДПИСЬ К ПОСТУ ═══
<подпись: начинается или заканчивается «Подпишись, чтобы не потерять», в конце «Не финансовая рекомендация.»>
═══ КОНЕЦ ═══
```

QC: есть блоки слайдов, слайдов ≤ 10, есть блок подписи, в подписи призыв + дисклеймер, без хэштегов (🟡). Строки «Визуал:» на слайд не попадают и на красные слова не проверяются.

## Как оркестратор пишет ячейки

Исполнитель возвращает текст ячейки целиком (или кладёт в файл). Оркестратор:
1. сохраняет в файл пули (`<Папка с медиа>/texts/heygen.txt` и т. п.);
2. прогоняет `python3 scripts/factory.py qc --file <файл> --kind heygen|threads|carousel` — до записи в таблицу;
3. пишет: `python3 scripts/factory.py set N --field "Сценарий HeyGen" --file <файл>`.

Эталон — первые пули таблицы «Единицы контента» (№1 «Трейдинг становится казино…»): все три ячейки оформлены по этому стандарту.
