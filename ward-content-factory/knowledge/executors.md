# Исполнители завода — кто что делает

Оркестратор вызывает исполнителей **субагентами** (инструмент Agent) по шаблону `templates/brief_executor.md`. Пути к скиллам — `config/settings.yml → executors`. Исполнитель получает только свою задачу и файлы бренда — без истории диалога и без соседних пуль.

## Сводка

| Исполнитель | Шаг (статус на входе → выходе) | Вход | Выход | Пачка | Пишет в Teable |
|---|---|---|---|---|---|
| **Субагент «пуля»** (без скилла, по `templates/brief_bullet.md` + `../_ward/`) | Идея → Пуля | строка пули (Идея: формулировка, инсайт, источник) | поля пули: сегмент, воронка, Хант, формула хука, хуки A/B/C, тезисы, доказательство, формат, CTA, красные линии, аватар | до 5 идей в агенте | оркестратор: `factory.py set` по полям, затем `status N "Пуля"` |
| **eman-scenario** | Пуля → (часть) Тексты готовы | пуля целиком + пресет аватара (`avatar_presets.md`) | ячейка «Сценарий HeyGen» по стандарту `cell_format_standard.md` | `texts_batch_size` пуль | `Сценарий HeyGen` + адаптация «П-NN · HeyGen» (TikTok, Reels, Shorts) |
| **threads-writer** | Пуля → (часть) Тексты готовы | пуля целиком; режим по умолчанию — атомарные посты (Pool), 2–4 поста | ячейка «Threads-посты» | `texts_batch_size` пуль | `Threads-посты` + адаптация на каждый пост «П-NN · Threads k/N» |
| **carousel** (текст) | Пуля → (часть) Тексты готовы | пуля целиком | ячейка «Текст карусели» (≤10 слайдов, подпись) | 🔴 **1 карусель = 1 субагент** | `Текст карусели` + адаптация «П-NN · Карусель» |
| **carousel** (рендер) | Тексты готовы → (часть) Медиа готовы | утверждённый текст карусели + дизайн-код Ward | папка со слайдами `01_…png … 10_…png` + `подпись_под_пост.md` | 🔴 1 карусель = 1 субагент, рендер последовательно | `Файлы` адаптации, `Папка с медиа` пули |
| **HeyGen** (API, без скилла — `workflows/media.md`) | Тексты готовы → (часть) Медиа готовы | текст между «▼ ТЕКСТ ДЛЯ ОЗВУЧКИ ▼ … ▲» + avatar_id/voice_id пресета | mp4 9:16 в папке пули | по одному видео, опрос статуса | `Файлы` адаптации |
| **Higgsfield** (MCP — `workflows/media.md`, `../_ward/Дизайн-код Ward.md`) | Тексты готовы → (часть) Медиа готовы | хук, тема, тип кадра | обложка 9:16 / фон слайда 4:5 / предметный кадр | ≤3 ретрая на картинку | `Файлы` адаптации |
| **zernio-posting** | На проверке («ок») → Запланировано → Опубликовано | папка с медиа + подпись, или текст Threads; дата/время из сетки | пост в расписании Zernio, ID поста; после выхода — ссылка | по одной адаптации | `Дата публикации`, `Заметки` (ID), `Ссылка на публикацию`, статус адаптации |
| **parsing-ward** | (вне конвейера) | своё расписание | строки «Отобранные новости» | — | 🔴 оркестратор только читает |

## Как выбирать исполнителей по полю «Формат»

| Значение в «Формат» | Кого звать на шаге «Тексты» | Медиа |
|---|---|---|
| AI-аватар (HeyGen) | eman-scenario | HeyGen (+ обложка Higgsfield) |
| Threads | threads-writer | не нужно |
| Карусель | carousel (текст) | carousel (рендер) (+ Higgsfield по дизайн-коду) |
| Talking head, Split screen, Моушен, Запись экрана, AI-сериал и др. | не автоматизировано — оркестратор пишет в «Красные линии / проверить»: «формат X — вручную», и не держит пулю: статус считается по автоматизируемым форматам | — |

## Что исполнитель обязан вернуть (приёмка)

1. **Отчёт о прочитанном:** список файлов скилла, которые прочитал (SKILL.md + модули), и `../_ward/` файлы.
2. **Отчёт о правилах:** какие жёсткие правила скилла применил (номер + 3–6 слов) и где отступил (с причиной).
3. **Результат:** текст ячейки ровно по `cell_format_standard.md` — либо путь к файлу с ним.
4. **Самопроверка красных линий:** «суммы / заработок-доход / биржи / ссылки / CTA / дисклеймер — проверено».

Нет пунктов 1–2 → результат не принимаем, перезапуск с тем же брифом и пометкой «в прошлый раз не было отчёта о правилах». Это не формальность: без явного требования агенты читают только оглавление скилла и пропускают модули.

## Частые ошибки исполнителей (что проверять при приёмке)

- eman-scenario: цифры в озвучке («50 USDT» вместо «пятьдесят USDT»), тире, нет «Подпишись, чтобы не потерять» в конце озвучки.
- threads-writer: связный тред вместо отдельных постов; пост > 500 символов; дисклеймер в посте (он в профиле).
- carousel: 11+ слайдов; финальный слайд не «Подпишись, чтобы не потерять»; дисклеймер забыт в подписи; соседние карусели «протекли» друг в друга (поэтому 1 на агента).
- Все: «заработок / доход» в подписи, названия бирж, ссылки.
