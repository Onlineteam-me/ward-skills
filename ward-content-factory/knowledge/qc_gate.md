# QC-гейт — проверка перед публикацией

Источник правил — `../_ward/Голос бренда Ward (ToV).md` → «Красные линии» и «Призыв к действию». Исполняемая версия — `scripts/factory.py` (блок «QC-гейт»: `RED`, `YELLOW`, `CTA_RE`, `DISCLAIMER_RE`). Если меняете правило — меняйте **в скрипте**, потом обновите таблицу здесь.

## Как запускать

```bash
python3 scripts/factory.py qc --unit 12                          # все ячейки пули по её «Формату»
python3 scripts/factory.py qc --file texts/heygen.txt --kind heygen   # файл до записи в Teable
python3 scripts/factory.py qc --unit 12 --json                   # машинный вывод для QC-отчёта
```

Код выхода: `1` — есть 🔴 (в постинг нельзя), `0` — 🟢 или 🟡.
Вердикты: **🔴 НЕ ПРОЙДЕН** → вернуть исполнителю · **🟡 ПРОЙДЕН с замечаниями** → человек смотрит каждое замечание · **🟢 ПРОЙДЕН**.

Что не проверяется на слова: блок `═══ ИНСТРУКЦИЯ ═══`, строки «Визуал:», «Символов:», «Каркас», «Субтитры:», «Проверить/подставить» и строки с «не использовать» (там цитируются сами правила).

## 🔴 Блокирующие правила

| Правило | Regex (без учёта регистра) | Почему |
|---|---|---|
| Слова теневого бана | `\bзаработ\w*\|\bзароб(і\|и)т\w*\|\bзаробля\w*\|\bдоход(а\|у\|ом\|ов\|ам\|ами\|ах\|е\|ы\|н\w*)?\b\|\bдохід\w*\|\bбыстр\w*\s+деньг\w*\|\bшвидк\w*\s+грош\w*` | соцсети режут охват; ToV запрещает в тексте на экране и подписях (озвучка = субтитры = экран) |
| Биржи, брокеры, конкуренты | `\b(binance\|bybit\|okx\|bitget\|mexc\|kucoin\|gate.io\|htx\|huobi\|bingx\|whitebit\|kraken\|coinbase\|…\|бинанс\w*\|байбит\w*\|…\|pocket option\|quotex\|binomo\|exness\|…\|cryptology\|vataga\|peterson)\b` — полный список в скрипте (`EXCHANGES`) | «Конкурентов, брокеров и биржи не называем» |
| Внешние ссылки | `https?://\|www\.\|\bt\.me/\|\b[\w-]+\.(com\|io\|net\|org\|ua\|ru\|me)\b` | теневой бан, ToV |
| Рубли | `₽\|\bруб(\.\|л\w*)?\b\|\brub\b` | валюта только $ или USDT |
| Обещание без риска | `\bбез\s+риск\w*\|\bгарантированн\w*\|\b100\s*%\s*(результат\|прибыл\|профит)` | «Нельзя "без риска", "гарантированно"» |
| Нет призыва (HeyGen-озвучка, подписи Reels и карусели) | наличие `подпиш\w*[^.\n]{0,40}(не\s+потерят\w*\|не\s+загубит\w*\|не\s+втратит\w*)` | единый CTA этапа запуска «Подпишись, чтобы не потерять» (вариации допустимы) |
| Нет дисклеймера (подписи Reels и карусели) | наличие `не\s+финансов\w*\s+рекомендац\w*\|не\s+фінансов\w*\s+(порад\w*\|рекомендац\w*)` | ToV: «Не финансовая рекомендация». В Threads — в профиле, в посте не нужен |
| Структура ячейки | маркеры `▼ ТЕКСТ ДЛЯ ОЗВУЧКИ ▼ … ▲ КОНЕЦ ТЕКСТА ▲`, `▼ ПОСТ k … ▲ КОНЕЦ ПОСТА k ▲`, `▼ СЛАЙД k из N`, `═══ ПОДПИСЬ К ПОСТУ ═══` | без маркеров редактор скопирует лишнее (`cell_format_standard.md`) |
| Лимиты площадок | пост Threads ≤ 500 символов; карусель ≤ 10 слайдов | API площадок не примет |
| Эмодзи/ссылки в озвучке HeyGen | эмодзи-диапазон или `https?://` в блоке озвучки | аватар их озвучит |

## 🟡 Смотрит человек

| Правило | Что ищем | Что решить |
|---|---|---|
| Суммы | `$5`, `50 USDT`, `3 000 $`, `500 к`, «пятьсот долларов» | это порог входа/пример риска (ок) или обещание результата (🔴, переписать)? «Заработал за N дней» — всегда 🔴 |
| «Гарант…» | `\bгарант\w*` | допустимо только в разоблачении («обещают гарантию — беги») |
| Глянец | Ламбо, роскошь, яхта, суперкар | только высмеивание (пресет «Бабушка у Ламбо» — по сценарию это норма) |
| Военная тема | война, фронт, ЗСУ, мобилизация | бережно, без эксплуатации травмы, акцент на навыках |
| Большое плечо | `x20`, `x100`, «плечо 50» | только как пример ошибки, с объяснением риска |
| Цифры и тире в озвучке | цифры, «—» / «–» в блоке озвучки | HeyGen читает криво — лучше словами / точкой |
| Хэштеги в подписи | `#слово` | по стандарту не используем |

## Ручной чек-лист (то, что regex не поймает) — пройти глазами перед «ок»

- [ ] Нет обещаний результата в любой форме: «выйдешь на…», «через месяц будешь…», «стабильный плюс».
- [ ] Минусы, стопы, рутина показаны так же честно, как плюсы.
- [ ] Голос: спокойный, на «ты», без капслока и «успешного успеха».
- [ ] Курс, Discord, KYC, лид-магниты **не продвигаем** (этап запуска) — только «Подпишись, чтобы не потерять».
- [ ] Факты и цифры — из источника (новость / ДНК), не выдуманы.
- [ ] Визуал по дизайн-коду: без денег, роскоши, азартной эстетики (`../_ward/Дизайн-код Ward.md` → «Чего нельзя»).
- [ ] В кадре нет логотипов бирж (скриншоты терминала — без названия биржи и без сумм).

## Что делать с результатом

- 🔴 → `factory.py status N "Пуля" --force --note "QC: <что>"` (если текст) или `"Тексты готовы"` (если медиа), бриф исполнителю с точными замечаниями из отчёта. Оркестратор сам не правит.
- 🟡/🟢 → `factory.py set N --field "QC-отчёт" --file <отчёт>` → `factory.py status N "На проверке"` → показать человеку `templates/qc_report.md`.
- «ок» человека → zernio-posting → `factory.py status N "Запланировано"` (движок ещё раз прогонит QC и не пустит с 🔴).
