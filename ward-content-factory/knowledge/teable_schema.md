# Схема Teable — база контент-завода Ward

4 таблицы. ID базы и таблиц — только в `config/settings.yml → teable` (мастер настройки подскажет). Здесь — поля, их тип и кто их пишет.

## API — что важно знать

- Адрес: `{api_url}` из настроек (например `https://app.teable.ai/api`). Заголовок `Authorization: Bearer <токен>` (токен — `config/secrets.yml`).
- **🔴 Максимум 100 записей за запрос.** Чтение всегда постранично: `GET /table/{tableId}/record?fieldKeyType=name&take=100&skip=0`, затем `skip=100`, `skip=200`… пока не придёт меньше 100. Движок (`factory.py`) делает это сам.
- Запись: `PATCH /table/{tableId}/record/{recordId}` с телом `{"record":{"fields":{...}},"fieldKeyType":"name","typecast":true}`. `typecast` позволяет писать варианты select по имени.
- Создание: `POST /table/{tableId}/record` с `{"records":[{"fields":{...}}],"fieldKeyType":"name","typecast":true}`.
- Поля таблицы: `GET /table/{tableId}/field`. Таблицы базы: `GET /base/{baseId}/table`.
- Варианты singleSelect добавляются через изменение поля (`PATCH /table/{tableId}/field/{fieldId}` с полным списком `options.choices`) — **только после «ок» человека**, старые варианты не удалять.

## 1. «Единицы контента» — одна строка = одна пуля (главная таблица завода)

| Поле | Тип | Кто пишет | Смысл |
|---|---|---|---|
| Пуля | однострочный текст (первичное) | оркестратор / субагент «пуля» | одна мысль одной фразой |
| № | число | движок (`next-number`) | сквозной номер, по нему команды «доведи пулю №N» |
| **Статус** | один выбор | только движок `factory.py status` | Идея / Пуля / Тексты готовы / Медиа готовы / На проверке / Запланировано / Опубликовано / Отклонено. 🔴 Сейчас в базе: Идея / В работе / Готово — мастер настройки предложит добавить недостающие |
| Приоритет | один выбор | человек / «пуля» | 🔥 Высокий / Средний / Низкий |
| Сегмент ДНК | множ. выбор | «пуля» | Н-1 Застрявший в найме, Н-2 Вернувшийся, Н-3 Эмигрант не по уровню, Н-4 Крипто-хомяк, Н-5 Обжёгшийся на глянце, Б Буксующие |
| Этап воронки | один выбор | «пуля» | TOFU / MOFU / BOFU |
| Ступень Ханта | один выбор | «пуля» | 0 не знает … 5 готов |
| Инсайт / боль | длинный текст | «пуля» / из новости | какую боль закрываем, цитата из ДНК |
| Источник в ДНК | однострочный | «пуля» | раздел ДНК или ссылка на новость |
| Формула хука | множ. выбор | «пуля» | Ф1–Ф12, E1–E12, H, «История / сериал» |
| Хук A / Хук B / Хук C | однострочные | «пуля» | три варианта хука |
| Тезисы тела | длинный текст | «пуля» | 3–5 тезисов |
| Доказательство в кадре | длинный текст | «пуля» | что показываем как пруф (терминал, журнал, стакан) |
| Формат | множ. выбор | «пуля» | AI-аватар (HeyGen), Карусель, Threads, Talking head, Split screen, Listicle, Моушен и др. Завод автоматизирует три: **AI-аватар (HeyGen), Карусель, Threads** |
| CTA | однострочный | «пуля» | на этапе запуска всегда «Подпишись, чтобы не потерять» |
| Доноры | длинный текст | «пуля» | ролики-доноры из «Ward Factory maine» |
| Красные линии / проверить | длинный текст | «пуля», движок (`--note`) | что проверить; сюда же причины возвратов/отклонений |
| Материалы | однострочный | человек / оркестратор | ссылки на исходники |
| Сценарий HeyGen | длинный текст | eman-scenario | по стандарту `cell_format_standard.md` |
| Threads-посты | длинный текст | threads-writer | по стандарту |
| Текст карусели | длинный текст | carousel | по стандарту |
| Адаптации | связь (один-ко-многим) → «Адаптации» | оркестратор | строки форматов этой пули |
| Адаптаций | rollup | Teable | счётчик |
| **Аватар** *(рекомендуется добавить)* | один выбор | «пуля» | Бабушка у Ламбо / Подкастер / Девушка в кафе / Ретро-трейдер — см. `avatar_presets.md` |
| **Папка с медиа** *(рекомендуется)* | однострочный | оркестратор | локальный путь к папке пули «П-NN …» |
| **QC-отчёт** *(рекомендуется)* | длинный текст | оркестратор | вывод `factory.py qc` + решения по 🟡 |

Готовые виды в базе: «Все пули», «🗂 Канбан по статусу», «👥 По сегменту», «🔻 По воронке», «🎣 По формуле хука», «🔥 Высокий приоритет», «💡 Идеи (не взяты в работу)».

## 2. «Адаптации» — одна строка = один формат пули под площадку

| Поле | Тип | Смысл |
|---|---|---|
| Название | однострочный (первичное) | «П-01 · HeyGen», «П-01 · Threads 1/3», «П-01 · Карусель» |
| Формат | один выбор | HeyGen-аватар, Говорящая голова, Моушен, Карусель, Threads-пост, Threads-тред, Text over B-roll, Split screen |
| Площадки | множ. выбор | TikTok, Instagram Reels, YouTube Shorts, Threads, Instagram карусель, Telegram |
| Статус | один выбор | Черновик / На согласовании / Готово к продакшну / В продакшне / Готово / Опубликовано (*рекомендуется добавить «Запланировано»*) |
| Язык | один выбор | RU / UA |
| Длина | однострочный | «~45 с · ~105 слов», «10 слайдов» |
| Хук | однострочный | хук этой адаптации |
| Сценарий / текст | длинный текст | текст именно для этой площадки |
| Визуал / B-roll | длинный текст | монтаж, таймкоды, визуал |
| Подпись к публикации | длинный текст | то, что уйдёт в описание поста |
| Дата публикации | дата | план → факт |
| Ссылка на публикацию | однострочный | ставит zernio-posting после выхода |
| Просмотры | число | аналитика |
| Файлы | однострочный | путь/имена файлов медиа |
| Заметки | длинный текст | ID поста Zernio, замечания |
| Пуля | связь (многие-к-одному) → «Единицы контента» | обратная связь |
| Сегмент (из пули), Приоритет (из пули), № пули | lookup | подтягиваются из пули |

Виды: «Все адаптации», «🗂 Канбан по статусу», «📱 По площадке», «🎬 По формату», «🤖 HeyGen-сценарии», «🧵 Threads», «👥 По сегменту пули», «📅 Календарь публикаций».

## 3. «Ward Factory maine» — банк роликов-доноров (только чтение)

Исследование ниши: ролики TikTok/Instagram с метриками. Оркестратор берёт отсюда доноров для пули (поле «Доноры»).
Ключевые поля: Хук / текст, Ссылка, Платформа, Аккаунт, Просмотры, Вирусность, Сохр. / просм., Язык, Тема (Скальпинг, Стакан и плотности, Новички / старт, День трейдера, Психология, Order flow, Крипта (общее), Разбор конкурента), Балл 1–10, Что работает, AI Avatar? (Да/Нет), 💎 Топ из топа, Хук дословно, Текст ролика.
Полезные виды: «💎 Топ из топа — RU», «🏆 Лучшие (балл 8–10)», «🔥 Топ по вирусности».

## 4. «Аккаунты» — аккаунты-доноры (только чтение)

Аккаунт, Профиль, Платформа, ✅ Шорт-лист, Группа (RU/UA — наша ниша, EN — банк форматов, Конкурент), Подписчики, Темы, Формат ролика, Что работает, AI Avatar?, Донор для контента, Медиана просмотров.

## 5. Таблица parsing-ward «Отобранные новости» (чужая, только чтение)

Живёт в базе parsing-ward (ID — `../parsing-ward/config/settings.yml → teable.tables.selected` или `teable.news_selected` здесь). Статусы: Новое / Утверждено / Отклонено. Оркестратор берёт строки «Утверждено» (или «Новое» с оценкой ≥ порога, если человек так скажет) — см. `workflows/ideas_from_news.md`. Схема полей — `../parsing-ward/knowledge/pipeline_architecture.md`.
