# Фото-основы AI-аватаров (заглушка)

Сюда кладутся исходные портреты 4 персонажей — по ним создаются фото-аватары в HeyGen. В пакет они не входят.

| Файл | Персонаж | Ключ в `config/settings.yml → heygen.avatars` |
|---|---|---|
| `babushka.png` | Бабушка у Ламбо | `babushka` |
| `podcaster.png` | Подкастер в домашней студии (неон WARD) | `podcaster` |
| `cafe_girl.png` | Девушка в кафе у моря | `cafe_girl` |
| `retro_trader.png` | Ретро-трейдер 1920-х со смартфоном | `retro_trader` |

Требования: вертикаль 9:16, лицо крупно и в фокусе, смотрит в камеру, рот закрыт, без текста и логотипов бирж. Стартовые промпты для генерации в Higgsfield — `../../knowledge/avatar_presets.md`.

После загрузки в HeyGen (Avatars → Photo Avatar) впишите ID аватара и выбранного голоса в `config/settings.yml` и скажите Claude «настрой завод» — мастер проверит, что ID существуют.
