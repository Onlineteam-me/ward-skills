# Workflow — «Доведи пулю №N»

**Вход:** «доведи пулю №12» [, «до текстов» / «до публикации»]. Без уточнения — до «На проверке» (дальше нужен «ок» человека).
**Итог:** пуля прошла все шаги от текущего статуса до цели; человек видит, что сделано и что ждёт его.

## Шаг 1 — где пуля

```bash
python3 scripts/factory.py show 12
python3 scripts/factory.py adapt-list 12
```
Определи статус (старые «В работе» / «Готово» — как «Пуля» / «Тексты готовы», `knowledge/status_model.md`). Сверь факт с полями: статус «Пуля», а ячейки текстов уже заполнены → значит, следующий шаг — QC текстов и перевод в «Тексты готовы», а не новый запуск исполнителя.

## Шаг 2 — пройти шаги по таблице

| Сейчас | Делаем | Потом |
|---|---|---|
| Идея | субагент «пуля» (`templates/brief_bullet.md`) → поля → `status 12 "Пуля"` | показать пулю, если `approve_bullets` |
| Пуля | исполнители текстов по «Формат» (параллельно; карусель — отдельный агент) → QC по файлам → `set` → `adapt` | `status 12 "Тексты готовы"` |
| Тексты готовы | `workflows/media.md` (HeyGen / рендер карусели / Higgsfield) → `Папка с медиа`, `Файлы` | `status 12 "Медиа готовы"` |
| Медиа готовы | `factory.py qc --unit 12` | 🔴 → назад; 🟢/🟡 → `QC-отчёт`, `status 12 "На проверке"` |
| На проверке | показать `templates/qc_report.md` + ближайшие свободные слоты сетки → ждать «ок» | «ок» → zernio-posting → `status 12 "Запланировано"` |
| Запланировано | проверить в Zernio, вышли ли посты; записать ссылки | всё вышло → `status 12 "Опубликовано"` |
| Опубликовано / Отклонено | ничего; сообщить человеку | — |

Исполнители — по `workflows/run_executors.md` (бриф, приёмка, отчёт о правилах).

## Шаг 3 — частичные случаи

- Человек просит переделать один формат («перепиши карусель») — запускаем только этот исполнитель, статус пули возвращаем на «Пуля» (`--force --note "переделка карусели"`), остальные ячейки не трогаем.
- В «Формат» есть неавтоматизируемые форматы (Talking head, Моушен…) — пишем в «Красные линии / проверить» «формат X — вручную» и ведём пулю по остальным.
- Нет ключа/аватара для шага — остановиться на предыдущем статусе и сказать, что нужно настроить (`workflows/setup.md`).

## Шаг 4 — отчёт

```
Пуля №12 «<пуля коротко>»: <было> → <стало>
Сделано: <форматы, файлы>
QC: 🟢 / 🟡 (<замечания>) / 🔴 (<что вернули>)
Ждёт тебя: <«ок» на публикацию в слоты …> / ничего
```
