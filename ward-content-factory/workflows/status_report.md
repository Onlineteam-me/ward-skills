# Workflow — «Что в работе»

**Вход:** «что в работе», «статус завода», «сводка по пулям».
**Итог:** короткая сводка по статусам + что делать дальше. Ничего не меняем, только читаем.

## Шаг 1 — данные

```bash
python3 scripts/factory.py summary
```
Движок читает все пули постранично (лимит Teable — 100 за запрос) и группирует по статусам в порядке модели. Старые статусы помечены «⚠️ старый статус».

Для «Запланировано» дополнительно: `factory.py adapt-list N` — даты публикаций, чтобы показать ближайшие выходы.

## Шаг 2 — ответ человеку

```
Всего пуль: 34

Идея — 9            → «новые идеи из новостей» не нужны; можно оформить 5 в пули
Пуля — 4            → №21, №22, №25, №30: ждут текстов
Тексты готовы — 6   → ждут медиа (видео HeyGen: 4, карусели: 2)
Медиа готовы — 2    → прогнать QC
На проверке — 3     → ждут твоего «ок»: №11, №14, №15
Запланировано — 7   → ближайшие: вт 19:00 TikTok №8, вт 12:30 карусель №13
Опубликовано — 3
Отклонено — 0

Следующий шаг: «доведи пулю №11» или «сделай контент на неделю».
```

Правила:
- Пули перечисляй номерами, текст пули — только если групп мало (≤ 5 строк на статус).
- Если есть старые статусы (`В работе`, `Готово`) — одной строкой предложи `factory.py infer` (перевод на модель после «ок»).
- Если в «На проверке» что-то лежит дольше 3 дней — отметь отдельно.
- Если «Запланировано» с датой публикации в прошлом и без ссылки — отметь «проверить, вышло ли» (zernio-posting).
