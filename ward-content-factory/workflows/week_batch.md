# Workflow — «Сделай контент на неделю»

**Вход:** «сделай контент на неделю» [, «на N пуль»] [, «только Threads и карусели»]. N по умолчанию — `pipeline.week_default_bullets`.
**Итог:** N пуль доведены до «На проверке», человек видит QC-отчёт и план публикаций; после «ок» — всё в расписании Zernio («Запланировано»).

Перед стартом: `python3 scripts/factory.py check` (тихо; если ❌ — `workflows/setup.md`).

---

## Шаг 1 — выбрать пули

1. `python3 scripts/factory.py summary`.
2. Берём в порядке: сначала то, что уже в работе (Медиа готовы → Тексты готовы → Пуля), потом Идеи с 🔥 Высокий приоритет, потом остальные Идеи.
3. Идей не хватает до N → предложить «новые идеи из новостей» (`workflows/ideas_from_news.md`) или взять из ДНК (субагент «пуля» сам предлагает идеи по `../_ward/ДНК клиента — новички.md`, бриф `templates/brief_bullet.md`, режим «придумать»).
4. Баланс недели: разные сегменты ДНК, ~60/30/10 TOFU/MOFU/BOFU, разные аватары (`knowledge/avatar_presets.md`). Покажи выбранный список одной таблицей (№ · пуля · статус · формат).

## Шаг 2 — Идея → Пуля

Субагенты «пуля» (`templates/brief_bullet.md`), до 5 идей в агенте, параллельно. Приём → `factory.py set` по полям → `factory.py status N "Пуля"`.
Если `pipeline.approve_bullets: true` — **стоп-точка:** покажи пули (хук A, формат, аватар, сегмент) и жди «ок» / правок. Правки → тот же агент-«пуля».

## Шаг 3 — Пуля → Тексты готовы

По полю «Формат» каждой пули (`knowledge/executors.md`):
- eman-scenario — пачками по `texts_batch_size`;
- threads-writer — пачками по `texts_batch_size`;
- carousel (текст) — 🔴 по одной на агента.
Все независимые агенты — одним сообщением параллельно (`workflows/run_executors.md`). Приёмка → QC по файлу → запись в ячейки → адаптации:

```bash
python3 scripts/factory.py adapt N --format "HeyGen-аватар" --platforms "TikTok,Instagram Reels,YouTube Shorts" --name "П-NN · HeyGen" --text-file <озвучка> --caption-file <подпись>
python3 scripts/factory.py adapt N --format "Threads-пост" --platforms "Threads" --name "П-NN · Threads 1/3" --text-file <пост 1>
python3 scripts/factory.py adapt N --format "Карусель" --platforms "Instagram карусель" --name "П-NN · Карусель" --caption-file <подпись>
python3 scripts/factory.py status N "Тексты готовы"
```

## Шаг 4 — Тексты готовы → Медиа готовы

`workflows/media.md`: видео HeyGen (по одному, с опросом статуса), рендер каруселей (1 агент = 1 карусель, последовательно), обложки Higgsfield по дизайн-коду. Тяжёлый этап — в Desktop можно вынести в отдельный чат (`run_executors.md`, шаг 3).
Папка пули → `factory.py set N --field "Папка с медиа" --value "<путь>"`; файлы → `adapt-set <rec> --field "Файлы" --value "<имена>"`; статус адаптаций «Готово». Пуля → «Медиа готовы». Пули без медиа (только Threads) переводятся сразу.
Аватар или ключ HeyGen не настроен → видео пропускаем, пуля остаётся «Тексты готовы», в отчёте человеку: «видео не сделано: нет avatar_id».

## Шаг 5 — QC → На проверке

Для каждой пули: `python3 scripts/factory.py qc --unit N`.
- 🔴 → назад исполнителю (`knowledge/qc_gate.md` → «Что делать с результатом»), повтор шага 3/4 для этой пули.
- 🟢/🟡 → `QC-отчёт` в пулю, статус «На проверке».

## Шаг 6 — план публикаций и «ок»

1. Разложить адаптации по сетке (`knowledge/publishing_grid.md`) → таблица `templates/week_plan.md`.
2. Показать человеку: план недели + QC-отчёт по каждой пуле (`templates/qc_report.md`, только 🟡 и ручной чек-лист). Ссылки на ячейки в Teable, тексты целиком не пересказывать.
3. **Стоп-точка 🔴: ждать «ок».** Частичный «ок» («всё кроме №7») — планируем только одобренное, №7 → правки или «Отклонено».

## Шаг 7 — Запланировано

Субагент zernio-posting (бриф `templates/brief_executor.md`, блок zernio-posting) получает утверждённый план: по каждой адаптации — файлы/текст, площадка, accountId из `config/settings.yml`, дата и время. Публикует **в расписание** (не сейчас).
После подтверждения от Zernio: в адаптацию — `Дата публикации`, `Заметки` (ID поста), статус «Запланировано»; пуля — `factory.py status N "Запланировано"`.

## Шаг 8 — отчёт

```
Неделя: <даты>
Запланировано: N пуль → X роликов, Y постов Threads, Z каруселей
Вернулось на доработку: №… (почему)
Не сделано: … (почему, что нужно от человека)
Календарь: Teable → «Адаптации» → вид «📅 Календарь публикаций»
```

После выхода постов (следующие запуски «что в работе») — проверить ссылки и перевести пули в «Опубликовано».
