# Маршрутизация контента — что и куда

Алгоритм определения «что у меня в руках и куда это идёт» по содержимому папки или строки Teable.

---

## Из локальной папки

| Что в папке | Тип публикации | Куда |
|---|---|---|
| 1 файл `*.mp4` (или `.mov`) + (опц.) `подпись.md` | **IG Reel** | Instagram (как Reel) |
| ≥2 файла (`*.jpg` или mix jpg+mp4) + (опц.) `подпись.md` | **IG Carousel** | Instagram (как Carousel) |
| Только `*.md` файлы (подпись/треды) | **Threads-only** | Threads (текст из `треды.md` или подпись) |
| `*.mp4` + `треды.md` | **Reel + Threads-текст** | 2 публикации (разное время) |
| `*.jpg…` + `треды.md` | **Carousel + Threads-текст** | 2 публикации (разное время) |

**Подпись для IG** берётся из:
1. `подпись_под_пост.md` (приоритет)
2. `подпись.md`
3. Имя файла + спрашиваем пользователя

**Текст для Threads** берётся из:
1. `треды.md` или `threads.md` в той же папке
2. Колонка «Тредс» в Teable (если строка существует)
3. Спрашиваем пользователя

---

## Из строки Teable (триггер `#<row_id>`)

```
1. GET запись → читаю поля
2. Колонка «Формат» (multi-select) → определяет что постим
3. Колонка «Текст» → caption для IG
4. Колонка «Тредс» → текст для Threads
5. Колонка «Когда публикуем» → предложить как слот (если в будущем)
6. Колонка «Медиа» (attachments) → ИЛИ скачать оттуда, ИЛИ найти локальную папку через «Папка с медиа»
```

### Маппинг «Формат» → публикации

| Формат в строке | Публикация |
|---|---|
| `["Карусель"]` | 1 публикация IG Carousel |
| `["Рилс"]` | 1 публикация IG Reel |
| `["Тредс"]` | 1 публикация Threads (из колонки «Тредс») |
| `["Карусель", "Тредс"]` | 2 публикации (IG + Threads, разное время) |
| `["Рилс", "Тредс"]` | 2 публикации |
| `["Карусель", "Рилс"]` | 2 публикации IG (разные слоты!) |
| `["Карусель", "Рилс", "Тредс"]` | 3 публикации (правило: одновременно IG-Carousel и IG-Reel не постим) |

## Куда `mv` локальную папку (тип архива)

`<archive_root>` = `config.yaml → local.archive_root`.

| Тип контента | Локальная папка-назначение |
|---|---|
| Carousel | `<archive_root>/Карусели/<имя_папки>/` |
| Reel | `<archive_root>/Рилсы/<имя_папки>/` |
| Threads-only | `<archive_root>/Тредс-посты/<имя_папки>/` |
| Carousel + Threads | копия в `Карусели/` (основная), Threads-текст как `треды.md` внутри |

> Если в одной строке IG + Threads — папка одна, не дублируется. Архив идёт по основному медийному типу.

---

## Эвристики для умолчаний

- В чате недавно работали с папкой `X` (например, только что сгенерировали карусель) → предлагаю её как «постим X?».
- В Teable есть строка со статусом «К публикации» и сегодняшней датой в «Когда публикуем» → предлагаю «может это?».
- Папка содержит `черновики/` → игнорирую её при архивировании.
- Имя папки совпадает с `Тема` существующей строки → обновляю, не создаю.
