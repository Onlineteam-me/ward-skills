# Workflow 01 — ROUTE (определить источник)

**Когда срабатывает:** при любом запуске `/zernio-posting`.
**Цель:** понять, откуда брать контент — локальная папка, строка Teable или ничего пока нет.

---

## Алгоритм

```
1. Разобрать аргумент команды:
   - "/zernio-posting <путь>"      → ветка PATH
   - "/zernio-posting #<row_id>"   → ветка ROW
   - "/zernio-posting"             → ветка ASK
   - "запости/опубликуй/выложи <X>" → распарсить X (путь или Teable URL/ID)

2. Если ASK без аргумента:
   - Посмотреть контекст чата: была ли недавно работа с папкой (`/carousel`, `/threads-writer`, генерация)?
     → Если да: «Запостить вот это: <путь>?»
   - Если нет: спросить «откуда контент: путь к папке или ID строки в Teable?»

3. Ветка PATH:
   - Bash: ls "<путь>" — проверить что папка существует и не пустая
   - Прочитать содержимое: какие файлы, есть ли подпись_под_пост.md
   - Передать в workflow 02 (DETECT)

4. Ветка ROW:
   - curl GET {{TEABLE_URL}}/api/table/{{TABLE_PUBLICATIONS}}/record/<row_id>
   - Прочитать «Формат», «Тема», «Текст», «Тредс», «Медиа», «Когда публикуем», «Папка с медиа» (локальный путь)
   - Если в «Медиа» есть attachments → есть откуда брать медиа
   - Если «Медиа» пустое, но «Папка с медиа» есть → использовать как локальный путь. Если путь не найден — искать в:
     - `<config.local.archive_root>/{Карусели,Рилсы,Тредс-посты}/`
     - папках из `config.local.source_hints` (если список не пустой)
   - Если нигде не найдено — спросить «где локальные файлы?»
```

---

## Что передаю в DETECT (схема внутреннего контекста)

```yaml
source_type: "path" | "row"
source_path: "<абсолютный путь>/папка"  # для path
source_row_id: "rec..."              # для row
existing_row: {...} | null           # если row или нашли в Teable по теме
files:
  - { name, size, mime, type: "image"|"video" }
caption_ig: "..." | null              # из подпись_под_пост.md или Текст
text_threads: "..." | null            # из треды.md или Тредс
scheduled_kogda: "2026-06-09T15:00" | null  # из колонки Когда публикуем
folder_name: "01_stop_loss_basics"    # для имени папки в архиве
```

---

## Проверки перед передачей дальше

- [ ] Папка существует и доступна для чтения
- [ ] В папке есть хотя бы 1 медиафайл ИЛИ есть треды.md/подпись.md
- [ ] Размер каждого медиа: jpg ≤ 4MB, mp4 ≤ 4MB (иначе помечаю «надо сжать»)
- [ ] Имя папки безопасное (без `..`, без `/`)
- [ ] Если ROW — проверил что запись действительно существует и status ещё не «Опубликовано»

---

## Возможные неудачи и реакция

| Проблема | Реакция |
|---|---|
| Путь не существует | Спросить «может имел в виду такую папку: ...?» (поиск по похожему) |
| Папка пустая | «В папке X пусто, что постить?» |
| `#row_id` не найден | «Не нашёл запись с ID `...` в Публикациях. Проверь правильность.» |
| Запись уже «Опубликовано» | Спросить «эта строка уже опубликована. Перепостить или другая?» |
| Слишком много файлов в карусели (>10 для IG) | См. workflow 03 — обрезать или предложить Threads |
