# Workflow 05 — ARCHIVE LOCAL

**Когда:** после `posts_get` вернул `status: "published"` (правило: не до публикации!).

**Цель:** перенести локальную папку с исходниками в архив `<config.local.archive_root>/<тип>/`.

---

## Алгоритм

```
1. Определить тип архива по типу публикации:
   - Carousel → "Карусели"
   - Reel → "Рилсы"
   - Threads-only → "Тредс-посты"
   - Carousel + Threads → "Карусели" (основное)
   - Reel + Threads → "Рилсы" (основное)

2. dest = "<config.local.archive_root>/<тип>/<folder_name>"
   - Если archive_root ещё заглушка {{ARCHIVE_ROOT}} → спросить пользователя, куда архивировать (или пропустить шаг с предупреждением)

3. Проверить что dest не существует:
   - Если существует: спросить пользователя «уже есть, перезаписать / переименовать / пропустить?»

4. Bash mv:
   mv "<source>" "<dest>"

5. Проверить успех:
   ls "<dest>" — должно показать те же файлы

6. Записать новый путь в контекст для workflow 07 (поле «Папка с медиа»)
```

---

## Edge cases

- **Если папки не в локальной FS (триггер был #row_id и медиа из Teable)** — пропускаем этот шаг, переходим сразу к 07 (update Teable).
- **Если уже есть папка с таким именем в архиве** — спросить.
- **Если в исходной папке есть `черновики/`** — переносим вместе с черновиками (это history, может пригодиться).

---

## Проверки

- [ ] Source существует и читается
- [ ] Dest родительская папка существует (`mkdir -p` если нет)
- [ ] После mv: source больше не существует, dest существует и содержит все файлы
